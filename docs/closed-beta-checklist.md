# Beta checklist

- Install the same-commit `pagenarrator-<version>.zip` artifact.
- Repeat webpage, selected-text, and PDF reads.
- Check all voices, highlights, cleanup, section pauses, resume, and 3× speed.
- Check that no account, payment, activation, or API key is required.
- Keep page text, URLs, browsing history, and audio out of exported diagnostics.
- Record installation, first audio, recovery, PDF, and long-read results against the tested build.
