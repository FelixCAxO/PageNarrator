# Reject zero-length KV inputs after an isolated repeat — 1 November 2026

The empty-cache prototype saves **3.70 MiB of retained main GPU allocation** and preserves every checked output. It is rejected because the clean comparison makes warm generation about **1% slower**, with all four paired warm medians worse. CPU results are mixed and dominated by one strong pair. The accepted [broadcast-mask implementation](broadcast-mask-20261101.md) remains unchanged.

## Calculation and captured dataflow

Every OmniVoice diffusion pass supplies the complete sequence and complete positions. The current runtime nevertheless creates a zero-filled previous cache with shape [1,8,L,128], shared by all 28 key and 28 value inputs. The proposed change supplies the same 56 inputs through an empty [1,8,0,128] tensor instead. Weights, prepared graph, attention positions, steps and sampling remain unchanged.

An artifact-only observer records every captured bind group's buffers and every copy source/destination in a real long request. Neither conditional nor unconditional commands bind the previous-cache buffer. The two buffers occupy 1,454,080 and 972,800 bytes at lengths 710 and 475. Empty inputs retain two four-byte GPU placeholders instead, removing 2,426,872 bytes from those input buffers. Logical host cache arrays also become empty. These are allocation and API-payload observations, not measured bus traffic or physical VRAM residency.

The intended equivalence follows the existing full-replacement cache assembly: retained prefixes and suffixes are empty, while current keys and values still enter attention. [ONNX Slice clamps forward boundaries to the input dimension](https://onnx.ai/onnx/operators/onnx__Slice.html). The captured command counts remain **647 / 646** for conditional/unconditional passes; this removes uploads and storage rather than matrix arithmetic. An additional 48 instrumented logit tensors and the long recording match exactly. Observer timings are excluded from cost claims.

A separate static metadata checker could not resolve a learned new-key shape. Its failed attempts are preserved and do not establish correctness at every boundary length. This is a checker limitation, not an observed inference failure.

## Clean full-request A/B

Four fresh-browser pairs alternate execution order. Each browser runs one 24-step paragraph and six 12-step requests. All **28 corresponding PCM comparisons are exact**. The unchanged 6 GiB browser Job cap and strict membership predicate hold for all **112 before/after observations**. Job user plus kernel CPU surrounds synthesis after initialization, including browser/worker/GPU-process host work, request transport, hashing and diagnostics. Peak commitment includes initialization.

Positive percentages mean lower candidate cost; warm latency compares the median of six corresponding requests within each pair.

| --- | ---: | ---: | ---: | ---: |
| 1 | 5.63% | -0.91% | -5.57% | -5.47% |
| 2 | 0.37% | -0.53% | 21.56% | 20.80% |
| 3 | 1.43% | -1.57% | 4.25% | -0.40% |
| 4 | 0.88% | -1.08% | -0.96% | -0.41% |

Paired median first latency improves 1.16%; warm latency worsens 0.99%. All-request CPU improves in two pairs and worsens in two: paired median reduction 1.65%, pooled reduction 5.29%. Warm CPU worsens in three pairs, with a paired median increase of 0.40%, despite a 3.99% pooled reduction. The pooled savings depend heavily on pair 2 and do not establish a consistent steady-state CPU improvement.

Main retained GPU allocation falls from **60,177,560 to 56,296,412 bytes**, a 3,881,148-byte saving. This exceeds the input-buffer calculation; the remaining allocator contribution is not separately isolated. Peak Job commitment improves in two pairs and worsens in two, with only 208,896 bytes (0.20 MiB) paired median saving. No whole-browser peak or resident-RAM reduction is established.

## Preserve the exploratory cohort

The first four-pair cohort overlapped briefly with a lightweight controller metadata check. That was an avoidable protocol mistake. Its raw data stays intact as exploratory evidence; it contributes no performance-saving claim. It also preserves 28 exact PCM comparisons and strict accounting observations.

That cohort showed a 233.05 MiB median commitment increase, which the isolated repeat does not reproduce. Some startup differences already occur before the first synthesis. The observed variation does not establish that zero-length caches cause a memory regression. The rejection rests on the clean steady-state latency/CPU tradeoff and the small allocation benefit, without selecting whichever cohort looks better.

## Verification and final state

- All **288 diffusion-step half-logit tensors** match within their adapter across NVIDIA and Intel. Six recording comparisons preserve codes, float32 PCM hashes and WAV bytes; test resources are released without device loss.
- All **77 artifact-only runtime tests** pass, including strengthened assertions for every key/value layer, zero logical size, shared ownership, full positions and disposal.
- Both cost cohorts pin their actual baseline and candidate workers. The measured candidate's reachable graph contains the empty-cache constructor. Current production TTS sources and worker dependencies match the previous accepted verification exactly. Separate PDF changes remain untouched.
- Full application tests, packaged broad-language playback and a new sustained soak are not repeated for this rejected prototype. The unchanged production application retains its previous 1,668-test and five-minute qualification.

Ignored artifacts/empty-kv-20261101/ contains both cost cohorts, source/package snapshots, binding traces, native output hashes, failed metadata-checker logs, summaries and verification. The clean cost run contains no other agent tests, builds, graph evaluation or measurements. Measurements/builds use the host-wide lock; unrelated host activity remains variable.

Only the current Ultra 9 / RTX 5090 PC is available, with Intel Xe-LPG controls. Physical 8 GiB RAM/VRAM, weaker dedicated GPUs, energy and real device audio remain unqualified. The goal stays active.
