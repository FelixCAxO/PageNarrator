PageNarrator bundles OmniVoice-generated references derived from FLEURS parent
references. The cards retain generated codec tokens and synthesis text, not
complete source recordings. Source metadata in src/tts/omnivoice/speaker-data.js
retain the dataset revision, language configuration, source filename,
attribution and URL, source-audio and encoder hashes, parent reference IDs/hash,
and generation settings/output-audio hash. Split, metadata/archive hashes and
parent preprocessing records are not retained in the current catalog; it is
not a complete source archive. Published reference transcripts are also used
as independent development test text, with source metadata retained there.

FLEURS recordings, transcripts and derived reference data retain CC BY 4.0.
