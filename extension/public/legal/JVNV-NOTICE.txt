PageNarrator bundles OmniVoice-generated references derived from JVNV parent
references. The cards retain generated codec tokens and synthesis text,
not complete publisher utterances. The adapted reference data retain
CC BY-SA 4.0. These changes do not imply endorsement by the contributors.

The source metadata in src/tts/omnivoice/speaker-data.js retain the published
reader ID, dataset attribution and URL, source-audio and encoder hashes,
parent reference IDs/hash, and generation settings/output-audio hash.
Archive member names/CRCs, archive index hashes, original transcript files/
hashes, publisher-page hashes and parent preprocessing records are not
retained in the current catalog. A parent hash alone does not locate an
original publisher utterance; this catalog is not a complete source archive.

The reference-data license is separate from the model and application-code
licenses. A release containing these references must include this notice
and the full CC BY-SA 4.0 license text.
