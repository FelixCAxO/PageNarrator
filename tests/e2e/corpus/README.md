# Public flow fixtures

These are PageNarrator-authored HTML controls under the repository license. Site-like names identify layout scenarios, not captured articles, endorsements, or current site behavior.

They test extraction order, page clutter, highlights, and playback. Passes do not qualify broad website coverage or held-out extraction quality.

Keep real captures in ignored `.cache/` or a private directory. `scripts/snapshot-corpus.mjs` refuses public fixture output. To exercise private captures, set `PN_E2E_CORPUS_DIR` to their directory; do not copy them into this folder or publish them without redistribution rights.
