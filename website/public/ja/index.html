PageNarrator 1.0.4

ウェブページやPDFを音声で聴く。

Chromeとデスクトップ版Chromiumブラウザ向けの無料オープンソース拡張機能。

推奨ハードウェア：8 GB 以上のシステム RAM と、8 GB 以上の VRAM を備えた専用 GPU（NVIDIA RTX 20 シリーズ以降、または WebGPU に対応した比較的新しい AMD Radeon）。

CPU のみで Kokoro を使う場合：6 コア以上の現代的な CPU と 8 GB 以上のシステム RAM を推奨します。起動に時間がかかり、音声の生成中に読み上げ区間の間で一時停止が発生する可能性があります。

OmniVoice には WebGPU と fp16 に対応した GPU が必要です。これらは目安となる構成であり、最低要件や、この仕様での滑らかな再生は検証されていません。

読み上げツール

テキストを追いながら聴く

ハイライト、読み上げテキスト、位置の保存、0.5×〜3×の速度調整。

PDF を開いて聴く

スキャンしたPDFの英語を端末内で認識するOCR。

自分に合った聴き方で

端末内で動く10種類の英語音声と、試験的な多言語対応のOmniVoice。

標準で端末内処理

内蔵の音声は端末内で動作

不足している音声ファイルは Hugging Face からダウンロードされます。 キャッシュ済みファイルは、同じ音声とモードならオフラインで使えます。保存データの削除やモードの変更後は、再ダウンロードが必要になる場合があります。 PageNarrator が読み上げのために、文章、PDF、URL、閲覧履歴を受け取ることはありません。
