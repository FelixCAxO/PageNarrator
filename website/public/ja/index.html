PageNarrator 1.0.1

文章を聴く。続きから読める。

端末内の音声でウェブページや PDF を読み上げ、テキストを同期してハイライトします。 無料・アカウント不要・利用回数制限なし。 バージョン 1.0.1 のソースコードは GitHub で公開されています。Chrome Web Store での公開は準備中です。

推奨： NVIDIA RTX 30 シリーズ以降の専用 GPU、8 GB 以上の VRAM、および 8 GB 以上のシステム RAM。

拡張機能を入手使い方
  • 音声は端末内で生成
  • アカウント不要・利用回数制限なし
  • ウェブページ、選択したテキスト、PDF

長い文章を読むために

読み上げツール

必要な部分だけ読む

記事やガイドから本文を抽出し、可能な範囲でページ内の余分な要素を除きます。

PDF を開いて聴く

PDF を表示したまま聴けます。テキストの選択、ズーム、ページの回転も可能です。

テキストを追いながら聴く

ページと読み上げテキストのハイライトが音声に合わせて進みます。

自分に合った聴き方で

速度を 0.5 倍から 3 倍に設定できます。コードの読み飛ばし、区間の間隔、ハイライトの色も調整できます。

あとで続きから

前回停止した位置から再開できます。読み上げテキストから区間を探すこともできます。

標準で端末内処理

内蔵の音声は端末内で動作

不足している音声ファイルは Hugging Face からダウンロードされます。 キャッシュ済みファイルは、同じ音声とモードならオフラインで使えます。保存データの削除やモードの変更後は、再ダウンロードが必要になる場合があります。 PageNarrator が読み上げのために、文章、PDF、URL、閲覧履歴を受け取ることはありません。
