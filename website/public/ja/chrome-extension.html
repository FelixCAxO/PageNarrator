ダウンロード

PageNarratorを入手

推奨： NVIDIA RTX 30 シリーズ以降の専用 GPU、8 GB 以上の VRAM、および 8 GB 以上のシステム RAM。

ウェブページ、選択したテキスト、PDFを読み上げます。音声合成は端末内で実行。無料で、アカウントも利用量の上限もありません。

v1.0.2のインストール

GitHubからv1.0.2をダウンロードしてください。Chrome ウェブストアの掲載ページはまだ利用できません。

  1. ZIP ファイルをダウンロードして展開します。
  2. chrome://extensionsを開き、デベロッパー モードを有効にします。
  3. パッケージ化されていない拡張機能を読み込むを選び、展開したフォルダーを選択します。
  4. 記事を開き、ツールバーのPageNarratorアイコンをクリックして、ページを読み上げるを選びます。
  5. 初回の音声ダウンロードと準備が完了するまで待ちます。

端末内のPDFを読む場合は、拡張機能の詳細でファイルの URL へのアクセスを許可するを有効にします。

パッケージ化されていない拡張機能の更新

再生を停止します。拡張機能の元のフォルダー内のファイルを、展開した ZIP の内容で置き換え、再読み込みをクリックして読み上げ中のタブを再読み込みします。設定と読書位置を保持するため、フォルダーのパスは変更しないでください。

音声とダウンロード

Kokoroには10種類の英語音声があります。初回の準備では、音声1種類を含めてCPU用に約93 MB、GPU用に約326 MBをダウンロードします。音声を1種類追加すると約0.5 MB必要です。利用できる場合はWebGPUを使い、それ以外では低速のCPU / WebAssemblyに切り替えます。試験対応のOmniVoiceには、fp16対応のWebGPUと約1.35 GBの個別ダウンロードが必要です。

未取得の音声ファイルはHugging Faceからダウンロードします。キャッシュしたファイルは同じ音声と処理モードでオフライン利用できます。音声やモードの変更、ストレージの消去、ブラウザーによるキャッシュ削除により、再ダウンロードが必要になる場合があります。

始める前に

デスクトップ版Chromium 120以降をご利用ください。上記のハードウェアは推奨条件であり、検証済みの最小要件ではありません。性能は端末と文書によって異なります。

ハイライトや読み上げテキストを確認し、保存した位置から再開し、速度を0.5×〜3×に調整できます。ポップアップを閉じても読み上げは続きます。

ソースからビルド

拡張機能を端末内でビルドします。Node.js 22.13+（22.x）または24+をインストールしてから、次の手順を実行してください。

  1. リポジトリをクローンし、PageNarratorフォルダーでターミナルを開きます。
  2. npm ciを実行します。
  3. npm run buildを実行します。
  4. chrome://extensionsからdist/を読み込みます。
