Transferência

Transfira o PageNarrator

Recomendado: uma GPU NVIDIA dedicada da série RTX 30 ou mais recente, com pelo menos 8 GB de VRAM e 8 GB de RAM do sistema.

Ouça páginas web, texto selecionado e PDFs. A fala é gerada no seu dispositivo. Gratuito, sem conta nem quota de uso.

Instale a v1.0.1

Compile a extensão a partir do código-fonte no GitHub. As transferências de versões anteriores já não estão disponíveis. A página na Chrome Web Store ainda não está disponível.

  1. Siga os passos de compilação do código-fonte abaixo para criar a pasta dist/.
  2. Abra chrome://extensions e ative o Modo de programador.
  3. Escolha Carregar expandida e selecione a pasta dist/.
  4. Abra um artigo, clique no ícone do PageNarrator na barra de ferramentas e escolha Ler página.
  5. Aguarde a conclusão da primeira transferência de voz e da preparação.

Para PDFs locais, ative Permitir acesso a URLs de ficheiro nos detalhes da extensão.

Obter o código-fonte

Atualize uma instalação expandida

Pare a reprodução, atualize a sua cópia local do código e execute npm ci e npm run build. Mantenha o mesmo caminho da pasta dist/. Abra chrome://extensions, clique em Recarregar na entrada existente e atualize os separadores de leitura. Manter a identidade da extensão preserva as definições e posições guardadas. Remover a extensão ou limpar o seu armazenamento apaga os dados locais de leitura.

Vozes e transferências

O Kokoro oferece dez vozes em inglês. A preparação inicial transfere cerca de 93 MB para CPU ou 326 MB para GPU, incluindo uma voz. Cada voz adicional precisa de cerca de 0,5 MB. O WebGPU é utilizado quando disponível, com CPU / WebAssembly como alternativa mais lenta. O OmniVoice experimental exige WebGPU com suporte a fp16 e uma transferência separada de cerca de 1,35 GB.

Os ficheiros de voz em falta são transferidos do Hugging Face. Os ficheiros em cache funcionam offline com a mesma voz e o mesmo modo de processamento. Trocar um deles, limpar o armazenamento ou a remoção automática da cache pelo navegador pode exigir uma nova transferência.

Antes de começar

Use Chromium 120 ou posterior num computador. O hardware indicado é uma recomendação, não um mínimo verificado. O desempenho depende do dispositivo e do documento.

Acompanhe os realces, use a transcrição, retome posições guardadas e ajuste a velocidade de 0,5× a 3×. A leitura continua quando o popup é fechado.

Ajuda de configuração · Privacidade

Compile a partir do código-fonte

Compile a extensão localmente. Instale Node.js 22.13+ (22.x) ou 24+ e depois:

  1. Clone o repositório e abra um terminal em PageNarrator.
  2. Execute npm ci.
  3. Execute npm run build.
  4. Carregue dist/ por chrome://extensions.
