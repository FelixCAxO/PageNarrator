Zásady ochrany soukromí

Soukromí

Poslední aktualizace: 26. října 2026

Data čtení

PageNarrator zpracovává text, PDF a zvýraznění v prohlížeči. Vestavěné hlasy Kokoro běží místně. Experimentální OmniVoice také běží na vašem zařízení. Anglické OCR soubory jsou součástí rozšíření. PageNarrator nedostává čtený obsah, adresy URL ani historii prohlížení pro předčítání.

Stahování vestavěných hlasů

Chybějící soubory se stahují z Hugging Face a jeho distribučních serverů. Ty dostávají vaši IP adresu a údaje o požadovaných souborech. Hugging Face nedostává text k předčítání. Soubory se ukládají v mezipaměti prohlížeče rozšíření a fungují offline se stejným hlasem a režimem, i po restartu. Změna hlasu nebo režimu, vymazání úložiště či automatické odstranění mezipaměti prohlížečem může vyžadovat nové stažení. Spustitelný kód je součástí rozšíření.

Online dokumenty

Online PDF se vyžadují od serveru dokumentu. Tento server dostává adresu URL a běžné údaje o připojení a může dostat existující přihlašovací údaje prohlížeče potřebné k otevření dokumentu. Jde o činnost oddělenou od vytváření řeči.

Úložiště rozšíření

Místní úložiště rozšíření obsahuje předvolby, vybrané hlasy, diagnostiku, adresy URL a názvy stránek a PDF, pozice a textový úryvek o délce až 160 znaků pro každou uloženou pozici. Modely používají mezipaměť prohlížeče. Tato data se nesynchronizují se servery PageNarrator.

Omezené použití dat v Chrome Web Store

Čtený obsah, adresy URL, nastavení, hlasy, diagnostika a pozice se používají pouze pro předčítání, zvýrazňování a pokračování ve čtení. PageNarrator tato data neprodává, nepoužívá je pro reklamu ani poskytování úvěrů, nepředává je k nesouvisejícím účelům a neumožňuje lidem je číst. PageNarrator dodržuje zásady uživatelských dat Chrome Web Store včetně požadavků na omezené použití (Limited Use).

Web a podpora

Web neobsahuje reklamní skripty ani sledování chování. Cloudflare zpracovává hostingové protokoly. Písma se poskytují z tohoto webu bez požadavků na Google Fonts. E-maily podpory slouží k odpovědím a vedení záznamů podpory.

Odstranění vašich dat

Aktualizace odstraňují vyřazená nastavení vlastních hlasů, klíče API a importované modely. Přerušené čištění se automaticky opakuje; data zůstávají do jeho dokončení. Místní data a hlasové soubory odstraníte vymazáním úložiště rozšíření nebo jeho odinstalováním.

Pro přístup, opravu nebo výmaz komunikace s podporou či jiné otázky ohledně soukromí napište na support@pagenarrator.com.
