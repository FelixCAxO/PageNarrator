Hämta PageNarrator

Rekommenderat: en dedikerad NVIDIA-GPU i RTX 30-serien eller senare, med minst 8 GB VRAM och 8 GB systemminne.

Lyssna på webbsidor, markerad text och PDF-filer. Talet skapas på din enhet. Gratis, utan konto eller användningskvot.

Installera v1.0.1

Bygg tillägget från källkoden på GitHub. Tidigare versioner går inte längre att hämta. Tillägget är ännu inte tillgängligt i Chrome Web Store.

  1. Följ bygganvisningarna för källkoden nedan för att skapa mappen dist/.
  2. Öppna chrome://extensions och aktivera Utvecklarläge.
  3. Välj Läs in opaketerat och välj mappen dist/.
  4. Öppna en artikel, klicka på PageNarrator-ikonen i verktygsfältet och välj Läs upp sidan.
  5. Vänta tills den första rösthämtningen och förberedelsen är klara.

Aktivera Tillåt åtkomst till filadresser i tilläggets information för att läsa lokala PDF-filer.

Hämta källkoden

Uppdatera en opaketerad installation

Stoppa uppspelningen, uppdatera din lokala kopia av källkoden och kör npm ci och npm run build. Behåll samma sökväg till mappen dist/. Öppna chrome://extensions, klicka på Läs in igen för det befintliga tillägget och uppdatera dina läsflikar. Samma tilläggsidentitet bevarar inställningar och sparade positioner. Om du tar bort tillägget eller rensar dess lagring raderas lokala läsdata.

Röster och hämtningar

Kokoro har tio engelska röster. Den första förberedelsen hämtar cirka 93 MB för CPU eller 326 MB för GPU, inklusive en röst. Varje extra röst kräver cirka 0,5 MB. WebGPU används när det är tillgängligt, med CPU / WebAssembly som ett långsammare alternativ. Experimentella OmniVoice kräver WebGPU med fp16-stöd och en separat hämtning på cirka 1,35 GB.

Röstfiler som saknas hämtas från Hugging Face. Cachelagrade filer fungerar offline med samma röst och bearbetningsläge. Om du byter något av dem, rensar lagringen eller webbläsaren automatiskt tömmer cachen kan en ny hämtning behövas.

Innan du börjar

Använd Chromium 120 eller senare på en dator. Hårdvaran ovan är en rekommendation, inte ett verifierat minimikrav. Prestandan beror på din enhet och ditt dokument.

Följ textmarkeringarna, använd uppläsningstexten, fortsätt från sparade positioner och ställ in hastigheten från 0,5× till 3×. Uppläsningen fortsätter när du stänger popupfönstret.

Installationshjälp · Integritet

Bygg från källkod

Bygg tillägget lokalt. Installera Node.js 22.13+ (22.x) eller 24+ och gör sedan så här:

  1. Klona kodförrådet och öppna en terminal i PageNarrator.
  2. Kör npm ci.
  3. Kör npm run build.
  4. Läs in dist/ via chrome://extensions.
