Support

Setup and help

Recommended: a dedicated NVIDIA RTX 30 series GPU or newer, with 8 GB+ VRAM and 8 GB+ system RAM.

Download v1.0.1 from GitHub. The Chrome Web Store listing is not available yet.

Update without losing your place

Update your local source copy, run npm ci and npm run build, and keep the same dist/ folder path. Click Reload on the existing entry at chrome://extensions, then refresh reading tabs. See the update instructions. Removing the extension or clearing its storage deletes saved reading data.

Install

Follow the source installation steps. Local PDFs need Allow access to file URLs in the extension's details.

Prepare a voice

Connect to the internet and choose Prepare voice or Read page. Missing files download from Hugging Face before speech starts.

The same cached voice and processing mode work offline. A different voice or mode, cleared storage, or browser eviction can require another download. If setup fails, check your connection and retry.

Choose processing

Kokoro supports WebGPU and a slower CPU / WebAssembly fallback. Advanced settings show the active path after reading starts. Experimental OmniVoice requires WebGPU with fp16 support and about 1.35 GB of downloads.

Physical hardware tiers are unverified. Performance depends on your device and document.

Troubleshooting

For Read selected, highlight a passage first. Protected browser pages cannot be read. Allow website access when prompted for a document you chose. For slow setup or speech, check the processing path in Advanced settings.

To remove saved reading data and voice files, clear the extension's storage or uninstall it.

Contact

Email support@pagenarrator.com. Include what you tried, the error, your Chrome version, and the active processing path. Leave out private text and document URLs.
