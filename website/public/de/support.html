Hilfe

Einrichtung und Hilfe

Empfohlen: eine dedizierte NVIDIA-GPU der RTX-30-Serie oder neuer mit mindestens 8 GB VRAM und 8 GB Arbeitsspeicher.

Laden Sie v1.0.1 von GitHub herunter. Der Eintrag im Chrome Web Store ist noch nicht verfügbar.

Aktualisieren und die Leseposition behalten

Aktualisieren Sie Ihre lokale Quellcodekopie, führen Sie npm ci und npm run build aus und behalten Sie denselben Pfad zu dist/ bei. Klicken Sie beim vorhandenen Eintrag unter chrome://extensions auf Neu laden und laden Sie Ihre Lesetabs neu. Siehe die Aktualisierungsanleitung. Das Entfernen der Erweiterung oder das Leeren ihres Speichers löscht die gespeicherten Lesedaten.

Installation

Folgen Sie der Installationsanleitung für den Quellcode. Aktivieren Sie für lokale PDFs in den Erweiterungsdetails Zugriff auf Datei-URLs zulassen.

Eine Stimme vorbereiten

Verbinden Sie sich mit dem Internet und wählen Sie Stimme vorbereiten oder Seite vorlesen. Fehlende Dateien werden vor dem Vorlesen von Hugging Face heruntergeladen.

Dieselbe zwischengespeicherte Stimme und derselbe Verarbeitungsmodus funktionieren offline. Ein Wechsel, gelöschter Speicher oder eine automatische Cache-Bereinigung durch den Browser kann einen erneuten Download erfordern. Prüfen Sie bei Einrichtungsfehlern Ihre Verbindung und versuchen Sie es erneut.

Verarbeitung wählen

Kokoro unterstützt WebGPU sowie CPU / WebAssembly als langsamere Alternative. Nach dem Start des Vorlesens zeigen die erweiterten Einstellungen den aktiven Verarbeitungsweg. Das experimentelle OmniVoice benötigt WebGPU mit fp16-Unterstützung und etwa 1,35 GB an Downloads.

Tests auf verschiedenen physischen Hardwareklassen stehen noch aus. Die Leistung hängt von Ihrem Gerät und Dokument ab.

Fehlerbehebung

Markieren Sie vor Auswahl vorlesen eine Passage. Geschützte Browserseiten können nicht vorgelesen werden. Erlauben Sie bei einer entsprechenden Aufforderung den Websitezugriff für das von Ihnen gewählte Dokument. Prüfen Sie bei langsamer Einrichtung oder Sprachausgabe den Verarbeitungsweg in den erweiterten Einstellungen.

Löschen Sie gespeicherte Lesedaten und Sprachdateien, indem Sie den Erweiterungsspeicher leeren oder die Erweiterung deinstallieren.

Kontakt

Schreiben Sie an support@pagenarrator.com. Beschreiben Sie Ihren Versuch, den Fehler, Ihre Chrome-Version und den aktiven Verarbeitungsweg. Senden Sie keine vertraulichen Texte oder Dokumentadressen.
