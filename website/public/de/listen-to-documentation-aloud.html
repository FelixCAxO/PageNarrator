Dokumentation anhören

Lassen Sie Anleitungen, API-Referenzen und Handbücher vorlesen, während die Seite sichtbar bleibt.

Im Text mitlesen

Hervorhebungen folgen der Sprachausgabe. Nutzen Sie den Lesetext, um Abschnitte zu finden, die Geschwindigkeit anzupassen oder an Ihrer letzten Position fortzufahren.

Code bei Bedarf überspringen

Aktivieren Sie bei Seiten mit viel Code Codeblöcke überspringen. Passen Sie Abschnittspausen und Hervorhebungsfarben in den erweiterten Einstellungen an.

Interne Dokumentation lokal verarbeiten

Die Sprachausgabe läuft auf Ihrem Gerät. PageNarrator erhält dafür weder den Text noch die URL oder Ihren Browserverlauf.
