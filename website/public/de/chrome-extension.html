PageNarrator herunterladen

Empfohlen: eine dedizierte NVIDIA-GPU der RTX-30-Serie oder neuer mit mindestens 8 GB VRAM und 8 GB Arbeitsspeicher.

Lassen Sie Webseiten, ausgewählten Text und PDFs vorlesen. Die Sprachausgabe läuft auf Ihrem Gerät. Kostenlos, ohne Konto und ohne Nutzungskontingent.

v1.0.1 installieren

Erstellen Sie die Erweiterung aus dem Quellcode auf GitHub. Downloads früherer Versionen sind nicht mehr verfügbar. Der Eintrag im Chrome Web Store ist noch nicht verfügbar.

  1. Folgen Sie unten der Anleitung zum Erstellen aus dem Quellcode, um den Ordner dist/ zu erzeugen.
  2. Öffnen Sie chrome://extensions und aktivieren Sie den Entwicklermodus.
  3. Wählen Sie Entpackte Erweiterung laden und anschließend den Ordner dist/.
  4. Öffnen Sie einen Artikel, klicken Sie in der Symbolleiste auf das PageNarrator-Symbol und wählen Sie Seite vorlesen.
  5. Warten Sie, bis der erste Sprachdownload und die Einrichtung abgeschlossen sind.

Aktivieren Sie für lokale PDFs in den Details der Erweiterung Zugriff auf Datei-URLs zulassen.

Quellcode herunterladen

Eine entpackte Installation aktualisieren

Beenden Sie die Wiedergabe, aktualisieren Sie Ihre lokale Quellcodekopie und führen Sie npm ci und npm run build aus. Behalten Sie denselben Pfad zum Ordner dist/ bei. Öffnen Sie chrome://extensions, klicken Sie beim vorhandenen Eintrag auf Neu laden und laden Sie Ihre Lesetabs neu. Bei gleicher Erweiterungsidentität bleiben Einstellungen und Lesepositionen erhalten. Das Entfernen der Erweiterung oder das Löschen ihres Speichers löscht die lokalen Lesedaten.

Stimmen und Downloads

Kokoro bietet zehn englische Stimmen. Bei der ersten Einrichtung werden einschließlich einer Stimme etwa 93 MB für die CPU oder 326 MB für die GPU heruntergeladen. Jede weitere Stimme benötigt etwa 0,5 MB. Wenn verfügbar, wird WebGPU verwendet; CPU / WebAssembly dient als langsamere Alternative. Das experimentelle OmniVoice benötigt WebGPU mit fp16-Unterstützung und einen separaten Download von etwa 1,35 GB.

Fehlende Sprachdateien werden von Hugging Face heruntergeladen. Zwischengespeicherte Dateien funktionieren mit derselben Stimme und demselben Verarbeitungsmodus offline. Ein Wechsel, das Löschen des Speichers oder eine automatische Cache-Bereinigung durch den Browser kann einen erneuten Download erforderlich machen.

Bevor Sie beginnen

Verwenden Sie Chromium 120 oder neuer auf einem Desktopcomputer. Die oben genannte Hardware ist eine Empfehlung und keine geprüfte Mindestanforderung. Die Leistung hängt von Ihrem Gerät und Dokument ab.

Folgen Sie den Hervorhebungen, nutzen Sie den Lesetext, setzen Sie gespeicherte Lesepositionen fort und wählen Sie eine Geschwindigkeit von 0,5× bis 3×. Die Sprachausgabe läuft weiter, wenn Sie das Popup schließen.

Aus dem Quellcode erstellen

Erstellen Sie die Erweiterung lokal. Installieren Sie Node.js 22.13+ (22.x) oder 24+ und gehen Sie dann so vor:

  1. Klonen Sie das Repository und öffnen Sie ein Terminal im Ordner PageNarrator.
  2. Führen Sie npm ci aus.
  3. Führen Sie npm run build aus.
  4. Laden Sie dist/ über chrome://extensions.
