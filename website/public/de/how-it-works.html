So funktioniert’s

Text wählen. Wiedergabe starten.

PageNarrator extrahiert Text und liest ihn auf Ihrem Gerät vor.

1. Lesetext auswählen

Mit Seite vorlesen beginnen Sie beim sichtbaren Abschnitt oder der gespeicherten Leseposition. Mit Auswahl vorlesen lassen Sie eine markierte Passage vorlesen. PageNarrator entfernt Navigation und störende Seitenelemente, soweit möglich.

2. Stimme vorbereiten

Die integrierten Kokoro-Stimmen laufen auf Ihrem Gerät. Fehlende Dateien werden von Hugging Face heruntergeladen. Wenn verfügbar, übernimmt WebGPU die Sprachausgabe; CPU / WebAssembly ist die langsamere Alternative. Das experimentelle OmniVoice benötigt WebGPU mit fp16-Unterstützung und einen eigenen Download.

Zwischengespeicherte Dateien funktionieren mit derselben Stimme und demselben Modus offline. Nach dem Löschen des Speichers oder einem Moduswechsel kann ein erneuter Download nötig sein.

3. Im Text mitlesen

Hervorhebungen folgen der Sprachausgabe. Nutzen Sie den Lesetext, pausieren Sie, wechseln Sie zwischen Abschnitten oder ändern Sie die Geschwindigkeit. Die Wiedergabe läuft weiter, wenn Sie das Popup schließen. Ihre Leseposition wird lokal gespeichert.

4. PDFs vorlesen lassen

Der PDF-Betrachter hält das Dokument beim Zuhören sichtbar. Markieren Sie Text, wechseln Sie Seiten, zoomen oder drehen Sie das Dokument. Für englischsprachige Scans wird lokale Texterkennung verwendet.
