Descărcare

Descarcă PageNarrator

Recomandat: un GPU NVIDIA dedicat din seria RTX 30 sau mai nou, cu cel puțin 8 GB VRAM și 8 GB RAM de sistem.

Ascultă pagini web, text selectat și PDF-uri. Vocea este generată pe dispozitivul tău. Gratuit, fără cont sau limită de utilizare.

Instalează v1.0.2

Descarcă v1.0.2 de pe GitHub. Pagina din Chrome Web Store nu este încă disponibilă.

  1. Descarcă fișierul ZIP și extrage-l.
  2. Deschide chrome://extensions și activează Modul pentru dezvoltatori.
  3. Alege Încarcă extensia neîmpachetată și selectează dosarul extras.
  4. Deschide un articol, apasă pictograma PageNarrator din bara de instrumente și alege Citește pagina.
  5. Așteaptă să se încheie prima descărcare a vocii și pregătirea.

Pentru PDF-uri locale, activează Permite accesul la adresele URL ale fișierelor în detaliile extensiei.

Actualizează o instalare neîmpachetată

Oprește redarea. Înlocuiește fișierele din dosarul original al extensiei cu conținutul ZIP-ului extras, apasă Reîncarcă și reîmprospătează filele de lectură. Păstrează aceeași cale a dosarului pentru a conserva setările și pozițiile de lectură.

Voci și descărcări

Kokoro oferă zece voci în engleză. Pregătirea inițială descarcă aproximativ 93 MB pentru CPU sau 326 MB pentru GPU, inclusiv o voce. Fiecare voce suplimentară necesită aproximativ 0,5 MB. Este folosit WebGPU când este disponibil; CPU / WebAssembly este alternativa mai lentă. OmniVoice experimental necesită WebGPU cu suport fp16 și o descărcare separată de aproximativ 1,35 GB.

Fișierele vocale lipsă sunt descărcate de pe Hugging Face. Fișierele din cache funcționează offline cu aceeași voce și același mod de procesare. Schimbarea unuia dintre acestea, ștergerea stocării sau eliminarea automată a cache-ului de către browser poate necesita o nouă descărcare.

Înainte de a începe

Folosește Chromium 120 sau o versiune ulterioară pe computer. Hardware-ul indicat este o recomandare, nu un minim verificat. Performanța depinde de dispozitiv și de document.

Urmărește evidențierea, folosește transcrierea, reia pozițiile salvate și setează viteza de la 0,5× la 3×. Citirea continuă când închizi fereastra extensiei.

Ajutor pentru configurare · Confidențialitate

Compilează din codul-sursă

Compilează extensia local. Instalează Node.js 22.13+ (22.x) sau 24+, apoi:

  1. Clonează depozitul și deschide un terminal în PageNarrator.
  2. Execută npm ci.
  3. Execută npm run build.
  4. Încarcă dist/ prin chrome://extensions.
