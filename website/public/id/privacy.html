Kebijakan privasi

Privasi

Terakhir diperbarui: 26 Oktober 2026

Data bacaan

PageNarrator memproses teks, PDF, dan sorotan di browser Anda. Suara bawaan Kokoro berjalan secara lokal. OmniVoice eksperimental juga berjalan di perangkat Anda. Berkas OCR bahasa Inggris disertakan dalam ekstensi. PageNarrator tidak menerima konten bacaan, URL, atau riwayat penelusuran untuk menghasilkan suara.

Unduhan suara bawaan

Berkas yang belum tersedia diunduh dari Hugging Face dan server distribusinya. Server tersebut menerima alamat IP Anda dan informasi berkas yang diminta. Hugging Face tidak menerima teks yang dibacakan. Berkas disimpan dalam cache browser milik ekstensi dan dapat digunakan secara offline untuk suara dan mode yang sama, termasuk setelah browser dimulai ulang. Mengganti suara atau mode, mengosongkan penyimpanan, atau penghapusan cache oleh browser mungkin mengharuskan pengunduhan ulang. Kode yang dapat dijalankan disertakan dalam ekstensi.

Dokumen online

PDF online diminta dari server tempat dokumen disimpan. Server tersebut menerima URL dan informasi koneksi biasa, serta mungkin menerima kredensial browser yang sudah ada dan diperlukan untuk membuka dokumen. Proses ini terpisah dari pembuatan suara.

Penyimpanan ekstensi

Penyimpanan lokal ekstensi menyimpan preferensi, pilihan suara, diagnostik, URL dan judul halaman serta PDF, posisi, dan kutipan teks hingga 160 karakter untuk setiap posisi tersimpan. Berkas model menggunakan cache browser. Data ini tidak disinkronkan ke server PageNarrator.

Penggunaan Terbatas Chrome Web Store

Konten bacaan, URL, pengaturan, suara, diagnostik, dan posisi hanya digunakan untuk pembacaan, penyorotan, dan melanjutkan bacaan. PageNarrator tidak menjual data ini, menggunakannya untuk iklan atau pemberian pinjaman, mentransfernya untuk tujuan yang tidak terkait, atau mengizinkan manusia membacanya. PageNarrator mematuhi Kebijakan Data Pengguna Chrome Web Store, termasuk persyaratan Penggunaan Terbatas.

Situs web dan dukungan

Situs web tidak memiliki skrip iklan atau pelacakan perilaku. Cloudflare memproses log hosting. Font disajikan dari situs web ini tanpa permintaan ke Google Fonts. Email dukungan digunakan untuk membalas dan menyimpan catatan dukungan.

Menghapus data Anda

Pembaruan menghapus pengaturan suara kustom yang sudah tidak digunakan, kunci API, dan model yang diimpor. Pembersihan yang terhenti dicoba ulang secara otomatis; data tetap ada hingga proses selesai. Hapus data lokal dan berkas suara dengan mengosongkan penyimpanan ekstensi atau menghapus pemasangannya.

Untuk akses, koreksi, penghapusan korespondensi dukungan, atau pertanyaan privasi lainnya, kirim email ke support@pagenarrator.com.
