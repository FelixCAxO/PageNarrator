Dapatkan PageNarrator

Disarankan: GPU NVIDIA khusus seri RTX 30 atau lebih baru, dengan VRAM minimal 8 GB dan RAM sistem minimal 8 GB.

Dengarkan halaman web, teks pilihan, dan PDF. Suara dihasilkan di perangkat Anda. Gratis. Tanpa akun atau kuota penggunaan.

Pasang v1.0.2

Unduh v1.0.2 dari GitHub. Halaman di Chrome Web Store belum tersedia.

  1. Unduh berkas ZIP lalu ekstrak.
  2. Buka chrome://extensions dan aktifkan Mode developer.
  3. Pilih Muat yang belum dipaketkan lalu pilih folder hasil ekstraksi.
  4. Buka artikel, klik ikon PageNarrator di toolbar, lalu pilih Baca halaman.
  5. Tunggu hingga pengunduhan suara pertama dan penyiapan selesai.

Untuk PDF lokal, aktifkan Izinkan akses ke URL file pada detail ekstensi.

Unduh v1.0.2Dapatkan kode sumberCatatan rilis

Memperbarui ekstensi yang dimuat tanpa pemaketan

Hentikan pemutaran. Ganti berkas di folder asli ekstensi dengan isi ZIP yang telah diekstrak, klik Muat ulang, lalu muat ulang tab bacaan. Pertahankan jalur folder yang sama agar pengaturan dan posisi baca tetap tersimpan.

Suara dan unduhan

Kokoro menyediakan sepuluh suara bahasa Inggris. Penyiapan pertama mengunduh sekitar 93 MB pada CPU atau 326 MB pada GPU, termasuk satu suara. Setiap suara tambahan memerlukan sekitar 0,5 MB. WebGPU digunakan jika tersedia, dengan CPU / WebAssembly yang lebih lambat sebagai cadangan. OmniVoice eksperimental memerlukan WebGPU dengan dukungan fp16 dan unduhan terpisah sekitar 1,35 GB.

Berkas suara yang belum tersedia diunduh dari Hugging Face. Berkas dalam cache bekerja secara offline untuk suara dan mode pemrosesan yang sama. Mengganti salah satunya, mengosongkan penyimpanan, atau penghapusan cache oleh browser mungkin mengharuskan pengunduhan ulang.

Sebelum memulai

Gunakan Chromium desktop versi 120 atau lebih baru. Perangkat keras di atas merupakan rekomendasi, bukan persyaratan minimum yang telah diverifikasi. Kinerja bergantung pada perangkat dan dokumen Anda.

Ikuti sorotan, gunakan transkrip, lanjutkan dari posisi tersimpan, dan atur kecepatan dari 0,5× hingga 3×. Pembacaan tetap berjalan saat Anda menutup popup.

Build dari kode sumber

Build ekstensi di perangkat Anda. Pasang Node.js 22.13+ (22.x) atau 24+, lalu:

  1. Klon repositori dan buka terminal di folder PageNarrator.
  2. Jalankan npm ci.
  3. Jalankan npm run build.
  4. Muat dist/ melalui chrome://extensions.
