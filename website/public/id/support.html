Bantuan

Penyiapan dan bantuan

Disarankan: GPU NVIDIA khusus seri RTX 30 atau lebih baru, dengan VRAM minimal 8 GB dan RAM sistem minimal 8 GB.

Unduh v1.0.1 dari GitHub. Halaman di Chrome Web Store belum tersedia.

Perbarui tanpa kehilangan posisi bacaan

Perbarui salinan kode sumber lokal Anda, jalankan npm ci dan npm run build, lalu pertahankan lokasi folder dist/. Klik Muat ulang pada entri ekstensi yang sudah ada di chrome://extensions, lalu muat ulang tab bacaan. Lihat petunjuk pembaruan. Menghapus ekstensi atau mengosongkan penyimpanannya akan menghapus data bacaan tersimpan.

Pemasangan

Ikuti langkah pemasangan dari kode sumber. PDF lokal memerlukan Izinkan akses ke URL file pada detail ekstensi.

Siapkan suara

Hubungkan ke internet dan pilih Siapkan suara atau Baca halaman. Berkas yang belum tersedia diunduh dari Hugging Face sebelum pembacaan dimulai.

Suara dan mode pemrosesan yang sama dalam cache dapat digunakan secara offline. Suara atau mode berbeda, penyimpanan yang dikosongkan, atau penghapusan cache oleh browser dapat mengharuskan pengunduhan ulang. Jika penyiapan gagal, periksa koneksi Anda lalu coba lagi.

Pilih pemrosesan

Kokoro mendukung WebGPU dan CPU / WebAssembly yang lebih lambat sebagai cadangan. Pengaturan lanjutan menampilkan jalur pemrosesan aktif setelah pembacaan dimulai. OmniVoice eksperimental memerlukan WebGPU dengan dukungan fp16 dan unduhan sekitar 1,35 GB.

Kinerja pada kelas perangkat keras fisik belum diverifikasi. Kinerja bergantung pada perangkat dan dokumen Anda.

Pemecahan masalah

Untuk Baca pilihan, sorot teks terlebih dahulu. Halaman browser yang dilindungi tidak dapat dibaca. Izinkan akses situs web saat diminta untuk dokumen yang Anda pilih. Jika penyiapan atau pembacaan lambat, periksa jalur pemrosesan di Pengaturan lanjutan.

Untuk menghapus data bacaan tersimpan dan berkas suara, kosongkan penyimpanan ekstensi atau hapus pemasangannya.

Kontak

Kirim email ke support@pagenarrator.com. Sertakan langkah yang dicoba, pesan kesalahan, versi Chrome, dan jalur pemrosesan aktif. Jangan sertakan teks pribadi dan URL dokumen.
