下载

下载 PageNarrator

建议： NVIDIA RTX 30 系列或更新的独立 GPU，至少 8 GB 显存和 8 GB 系统内存。

收听网页、所选文本和 PDF。语音在设备上生成。免费，无需账号，也没有使用配额。

安装 v1.0.1

使用 GitHub 上的源代码构建扩展程序。旧版本已不再提供下载。Chrome Web Store 页面尚未开放。

  1. 按照下方源代码构建步骤创建 dist/ 文件夹。
  2. 打开 chrome://extensions，启用开发者模式。
  3. 选择加载已解压的扩展程序，然后选择 dist/ 文件夹。
  4. 打开一篇文章，点击工具栏中的 PageNarrator 图标，选择朗读页面。
  5. 等待首次语音下载及准备完成。

如需读取本地 PDF，请在扩展程序详情中启用允许访问文件网址。

获取源代码

更新已解压的安装版本

停止播放，更新本地源代码副本，运行 npm ci 和 npm run build。保持 dist/ 文件夹路径不变。打开 chrome://extensions，在现有扩展项上点击重新加载，再刷新阅读标签页。保留相同的扩展身份可保留设置及阅读位置。移除扩展或清空其存储空间会删除本地阅读数据。

语音与下载

Kokoro 提供 10 种英语音色。首次准备需下载约 93 MB（CPU）或 326 MB（GPU），其中包含一种音色。每种额外音色约需 0.5 MB。可用时使用 WebGPU，CPU / WebAssembly 则是较慢的备用方式。实验性 OmniVoice 需要支持 fp16 的 WebGPU，并需单独下载约 1.35 GB。

缺少的语音文件从 Hugging Face 下载。缓存的文件可在使用相同语音和处理模式时离线运行。更改其中任一项、清空存储空间，或浏览器自动清除缓存，都可能需要重新下载。

开始之前

请使用电脑端 Chromium 120 或更新版本。上述硬件配置是建议，并非经过验证的最低要求。性能取决于设备和文档。

跟随高亮、查看文本记录、恢复已保存的位置，并将速度设为 0.5× 至 3×。关闭弹出窗口后，朗读会继续。

从源代码构建

在本地构建扩展程序。安装 Node.js 22.13+（22.x）或 24+，然后：

  1. 克隆代码仓库，在 PageNarrator 目录中打开终端。
  2. 运行 npm ci。
  3. 运行 npm run build。
  4. 通过 chrome://extensions 加载 dist/。
