帮助

设置与帮助

建议： NVIDIA RTX 30 系列或更新的独立 GPU，至少 8 GB 显存和 8 GB 系统内存。

从 GitHub 下载 v1.0.2。Chrome Web Store 页面尚未开放。

下载 v1.0.2获取源代码版本说明

更新时保留阅读位置

停止播放。用解压后的 ZIP 内容替换扩展程序原文件夹中的文件，点击重新加载，然后刷新阅读标签页。保持文件夹路径不变，以保留设置和阅读位置。

安装

按照从源代码安装的步骤操作。本地 PDF 需要在扩展详情中启用允许访问文件网址。

准备语音

连接互联网，选择准备语音或朗读页面。缺少的文件会在朗读开始前从 Hugging Face 下载。

相同的缓存语音和处理模式可以离线运行。更换语音或模式、清空存储空间，或浏览器自动清除缓存，都可能需要重新下载。准备失败时，请检查连接并重试。

选择处理方式

Kokoro 支持 WebGPU，以及较慢的备用方式 CPU / WebAssembly。开始朗读后，高级设置会显示当前处理方式。实验性 OmniVoice 需要支持 fp16 的 WebGPU，并需下载约 1.35 GB。

不同实体硬件档次尚未完成验证。性能取决于设备和文档。

故障排除

使用朗读所选内容前，请先选中一段文本。受保护的浏览器页面无法朗读。对于您选择的文档，请在出现提示时允许网站访问。如果准备或朗读较慢，请在高级设置中检查处理方式。

清空扩展存储或卸载扩展，即可删除保存的阅读数据和语音文件。

联系

请发邮件至 support@pagenarrator.com，说明尝试的操作、错误、Chrome 版本和当前处理方式。请勿附上私密文本或文档地址。
