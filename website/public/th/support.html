ความช่วยเหลือ

การตั้งค่าและความช่วยเหลือ

แนะนำ: GPU แยก NVIDIA RTX 30 ซีรีส์หรือใหม่กว่า พร้อม VRAM อย่างน้อย 8 GB และ RAM ระบบอย่างน้อย 8 GB

ดาวน์โหลด v1.0.1 จาก GitHub ยังไม่มีหน้ารายการบน Chrome เว็บสโตร์

อัปเดตโดยไม่สูญเสียตำแหน่งที่อ่าน

อัปเดตสำเนาซอร์สโค้ดในเครื่อง เรียกใช้ npm ci และ npm run build โดยใช้เส้นทางโฟลเดอร์ dist/ เดิม คลิกโหลดซ้ำที่ส่วนขยายรายการเดิมใน chrome://extensions แล้วรีเฟรชแท็บที่อ่านอยู่ ดูคำแนะนำการอัปเดต การลบส่วนขยายหรือล้างพื้นที่จัดเก็บจะลบข้อมูลการอ่านที่บันทึกไว้

ติดตั้ง

ทำตามขั้นตอนติดตั้งจากซอร์สโค้ด สำหรับ PDF ในเครื่อง ต้องเปิดอนุญาตให้เข้าถึง URL ของไฟล์ในหน้ารายละเอียดของส่วนขยาย

เตรียมเสียง

เชื่อมต่ออินเทอร์เน็ต แล้วเลือกเตรียมเสียงหรืออ่านหน้าเว็บ ไฟล์ที่ยังไม่มีจะดาวน์โหลดจาก Hugging Face ก่อนเริ่มอ่าน

เสียงและโหมดประมวลผลเดิมที่อยู่ในแคชใช้แบบออฟไลน์ได้ การใช้เสียงหรือโหมดอื่น การล้างพื้นที่จัดเก็บ หรือการที่เบราว์เซอร์ลบแคชอาจทำให้ต้องดาวน์โหลดใหม่ หากเตรียมเสียงไม่สำเร็จ ให้ตรวจสอบการเชื่อมต่อแล้วลองอีกครั้ง

เลือกวิธีประมวลผล

Kokoro รองรับ WebGPU และใช้ CPU / WebAssembly ที่ช้ากว่าเป็นวิธีสำรอง การตั้งค่าขั้นสูงจะแสดงวิธีที่ใช้อยู่หลังเริ่มอ่าน OmniVoice ในขั้นทดลองต้องใช้ WebGPU ที่รองรับ fp16 และดาวน์โหลดประมาณ 1.35 GB

ยังไม่ได้ยืนยันการทำงานบนฮาร์ดแวร์จริงแต่ละระดับ ประสิทธิภาพขึ้นอยู่กับอุปกรณ์และเอกสารของคุณ

การแก้ปัญหา

หากต้องการใช้อ่านข้อความที่เลือก ให้เลือกข้อความก่อน ไม่สามารถอ่านหน้าที่เบราว์เซอร์ป้องกันไว้ได้ อนุญาตการเข้าถึงเว็บไซต์เมื่อระบบขอสำหรับเอกสารที่คุณเลือก หากการเตรียมเสียงหรือการอ่านช้า ให้ตรวจสอบวิธีประมวลผลในการตั้งค่าขั้นสูง

หากต้องการลบข้อมูลการอ่านที่บันทึกไว้และไฟล์เสียง ให้ล้างพื้นที่จัดเก็บของส่วนขยายหรือถอนการติดตั้ง
