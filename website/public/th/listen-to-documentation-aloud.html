ฟังเอกสารคู่มือ

ฟังคู่มือ เอกสารอ้างอิง API และวิธีใช้งาน พร้อมดูหน้าเอกสารไปด้วย

ติดตามข้อความ

ไฮไลต์จะเลื่อนตามเสียงอ่าน ใช้ข้อความถอดเสียงเพื่อค้นหาส่วนที่ต้องการ ปรับความเร็ว หรืออ่านต่อจากจุดที่หยุดไว้

ข้ามโค้ดเมื่อต้องการ

เปิดข้ามส่วนโค้ดสำหรับหน้าที่มีโค้ดจำนวนมาก ปรับการเว้นช่วงระหว่างส่วนและสีไฮไลต์ได้ในการตั้งค่าขั้นสูง

เก็บเอกสารภายในไว้ในเครื่อง

การสร้างเสียงทำงานบนอุปกรณ์ของคุณ PageNarrator ไม่ได้รับข้อความ URL หรือประวัติการท่องเว็บเพื่อนำมาอ่านออกเสียง

รายละเอียดความเป็นส่วนตัว.
