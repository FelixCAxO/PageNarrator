รับ PageNarrator

แนะนำ: GPU แยก NVIDIA RTX 30 ซีรีส์หรือใหม่กว่า พร้อม VRAM อย่างน้อย 8 GB และ RAM ระบบอย่างน้อย 8 GB

ฟังหน้าเว็บ ข้อความที่เลือก และ PDF การสร้างเสียงทำงานบนอุปกรณ์ของคุณ ใช้ฟรี ไม่ต้องมีบัญชีและไม่มีโควตาการใช้งาน

ติดตั้ง v1.0.1

บิลด์ส่วนขยายจากซอร์สโค้ดบน GitHub ไม่สามารถดาวน์โหลดรุ่นเก่าได้อีกต่อไป และยังไม่มีหน้ารายการบน Chrome เว็บสโตร์

  1. ทำตามขั้นตอนบิลด์จากซอร์สโค้ดด้านล่างเพื่อสร้างโฟลเดอร์ dist/
  2. เปิด chrome://extensions แล้วเปิดใช้งานโหมดนักพัฒนาซอฟต์แวร์
  3. เลือกโหลดส่วนขยายที่คลายการแพคแล้ว แล้วเลือกโฟลเดอร์ dist/
  4. เปิดบทความ คลิกไอคอน PageNarrator บนแถบเครื่องมือ แล้วเลือกอ่านหน้าเว็บ
  5. รอให้การดาวน์โหลดเสียงครั้งแรกและการเตรียมเสียงเสร็จสิ้น

สำหรับ PDF ในเครื่อง ให้เปิดอนุญาตให้เข้าถึง URL ของไฟล์ในหน้ารายละเอียดของส่วนขยาย

รับซอร์สโค้ด

อัปเดตส่วนขยายที่ติดตั้งแบบคลายแพ็ก

หยุดเล่น อัปเดตสำเนาซอร์สโค้ดในเครื่อง แล้วเรียกใช้ npm ci และ npm run build ใช้เส้นทางโฟลเดอร์ dist/ เดิม เปิด chrome://extensions คลิกโหลดซ้ำที่ส่วนขยายรายการเดิม แล้วรีเฟรชแท็บที่อ่านอยู่ การคงรหัสส่วนขยายเดิมจะรักษาการตั้งค่าและตำแหน่งที่บันทึกไว้ การลบส่วนขยายหรือล้างพื้นที่จัดเก็บจะลบข้อมูลการอ่านในเครื่อง

เสียงและการดาวน์โหลด

Kokoro มีเสียงภาษาอังกฤษ 10 เสียง การเตรียมครั้งแรกจะดาวน์โหลดประมาณ 93 MB สำหรับ CPU หรือ 326 MB สำหรับ GPU รวมเสียงหนึ่งเสียง เสียงเพิ่มเติมแต่ละเสียงใช้ประมาณ 0.5 MB ระบบจะใช้ WebGPU เมื่อพร้อมใช้งาน และใช้ CPU / WebAssembly ที่ช้ากว่าเป็นวิธีสำรอง OmniVoice ในขั้นทดลองต้องใช้ WebGPU ที่รองรับ fp16 และดาวน์โหลดแยกประมาณ 1.35 GB

ไฟล์เสียงที่ยังไม่มีจะดาวน์โหลดจาก Hugging Face ไฟล์ในแคชใช้แบบออฟไลน์ได้เมื่อใช้เสียงและโหมดประมวลผลเดิม การเปลี่ยนอย่างใดอย่างหนึ่ง การล้างพื้นที่จัดเก็บ หรือการที่เบราว์เซอร์ลบแคชอาจทำให้ต้องดาวน์โหลดใหม่

ก่อนเริ่มใช้งาน

ใช้ Chromium บนเดสก์ท็อปรุ่น 120 ขึ้นไป ฮาร์ดแวร์ข้างต้นเป็นคำแนะนำ ไม่ใช่ข้อกำหนดขั้นต่ำที่ผ่านการยืนยัน ประสิทธิภาพขึ้นอยู่กับอุปกรณ์และเอกสารของคุณ

ติดตามไฮไลต์ ใช้ข้อความถอดเสียง อ่านต่อจากตำแหน่งที่บันทึกไว้ และปรับความเร็วตั้งแต่ 0.5× ถึง 3× การอ่านจะดำเนินต่อเมื่อคุณปิดป๊อปอัป

บิลด์จากซอร์สโค้ด

บิลด์ส่วนขยายในเครื่อง ติดตั้ง Node.js 22.13+ (22.x) หรือ 24+ แล้วทำตามขั้นตอนต่อไปนี้:

  1. โคลนที่เก็บโค้ด แล้วเปิดเทอร์มินัลใน PageNarrator
  2. เรียกใช้ npm ci
  3. เรียกใช้ npm run build
  4. โหลด dist/ ผ่าน chrome://extensions
