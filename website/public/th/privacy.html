อัปเดตล่าสุด: 26 ตุลาคม 2026

ข้อมูลการอ่าน

PageNarrator ประมวลผลข้อความ PDF และไฮไลต์ในเบราว์เซอร์ของคุณ เสียง Kokoro ในตัวทำงานในเครื่อง OmniVoice ในขั้นทดลองก็ทำงานบนอุปกรณ์ของคุณเช่นกัน ไฟล์ OCR ภาษาอังกฤษรวมอยู่ในส่วนขยาย PageNarrator ไม่ได้รับเนื้อหาที่อ่าน URL หรือประวัติการท่องเว็บเพื่อนำมาอ่านออกเสียง

การดาวน์โหลดเสียงในตัว

ไฟล์ที่ยังไม่มีจะดาวน์โหลดจาก Hugging Face และเซิร์ฟเวอร์จัดส่งไฟล์ของบริการนี้ เซิร์ฟเวอร์จะได้รับที่อยู่ IP และข้อมูลไฟล์ที่ขอ Hugging Face ไม่ได้รับข้อความที่จะอ่าน ไฟล์จะเก็บในแคชของเบราว์เซอร์สำหรับส่วนขยาย และใช้แบบออฟไลน์ได้เมื่อใช้เสียงและโหมดเดิม รวมถึงหลังจากเริ่มระบบใหม่ การเปลี่ยนเสียงหรือโหมด การล้างพื้นที่จัดเก็บ หรือการที่เบราว์เซอร์ลบแคชอาจทำให้ต้องดาวน์โหลดใหม่ โค้ดที่ใช้รันโปรแกรมรวมอยู่ในส่วนขยาย

เอกสารออนไลน์

ระบบจะขอ PDF ออนไลน์จากเซิร์ฟเวอร์ที่เก็บเอกสาร เซิร์ฟเวอร์นั้นได้รับ URL และข้อมูลการเชื่อมต่อตามปกติ และอาจได้รับข้อมูลรับรองที่มีอยู่ในเบราว์เซอร์ซึ่งจำเป็นต่อการเปิดเอกสาร กระบวนการนี้แยกจากการสร้างเสียง

พื้นที่จัดเก็บของส่วนขยาย

พื้นที่จัดเก็บในเครื่องของส่วนขยายเก็บค่ากำหนด เสียงที่เลือก ข้อมูลวินิจฉัย URL และชื่อของหน้าเว็บกับ PDF ตำแหน่ง และข้อความบางส่วนไม่เกิน 160 อักขระต่อตำแหน่งที่บันทึกไว้ ไฟล์โมเดลใช้แคชของเบราว์เซอร์ ข้อมูลเหล่านี้ไม่ซิงค์ไปยังเซิร์ฟเวอร์ PageNarrator

การใช้งานแบบจำกัดของ Chrome เว็บสโตร์

เนื้อหาที่อ่าน URL การตั้งค่า เสียง ข้อมูลวินิจฉัย และตำแหน่ง ใช้สำหรับการอ่านออกเสียง ไฮไลต์ และอ่านต่อเท่านั้น PageNarrator ไม่ขายข้อมูลนี้ ไม่ใช้เพื่อโฆษณาหรือการให้สินเชื่อ ไม่ส่งต่อเพื่อวัตถุประสงค์ที่ไม่เกี่ยวข้อง และไม่อนุญาตให้มนุษย์อ่านข้อความดังกล่าว PageNarrator ปฏิบัติตามนโยบายข้อมูลผู้ใช้ของ Chrome เว็บสโตร์ รวมถึงข้อกำหนดการใช้งานแบบจำกัด

เว็บไซต์และการสนับสนุน

เว็บไซต์ไม่มีสคริปต์โฆษณาหรือติดตามพฤติกรรม Cloudflare ประมวลผลบันทึกการให้บริการโฮสติ้ง แบบอักษรให้บริการจากเว็บไซต์นี้โดยไม่ส่งคำขอไปยัง Google Fonts อีเมลฝ่ายสนับสนุนใช้เพื่อตอบกลับและเก็บประวัติการช่วยเหลือ

ลบข้อมูลของคุณ

การอัปเกรดจะลบการตั้งค่าเสียงกำหนดเอง คีย์ API และโมเดลที่นำเข้าซึ่งเลิกใช้แล้ว หากการล้างข้อมูลถูกขัดจังหวะ ระบบจะลองใหม่อัตโนมัติ โดยข้อมูลยังคงอยู่จนกว่าจะเสร็จ ลบข้อมูลในเครื่องและไฟล์เสียงได้ด้วยการล้างพื้นที่จัดเก็บของส่วนขยายหรือถอนการติดตั้ง

หากต้องการเข้าถึง แก้ไข หรือลบข้อความที่ติดต่อฝ่ายสนับสนุน หรือมีคำถามอื่นเกี่ยวกับความเป็นส่วนตัว ส่งอีเมลไปที่ support@pagenarrator.com
