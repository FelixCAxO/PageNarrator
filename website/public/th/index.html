ฟังข้อความ แล้วอ่านต่อได้ตรงจุดเดิม

ฟังหน้าเว็บและ PDF ด้วยเสียงในอุปกรณ์ พร้อมไฮไลต์ข้อความตามเสียงอ่าน ใช้ฟรี ไม่ต้องมีบัญชีและไม่มีโควตาการใช้งาน ซอร์สโค้ดเวอร์ชัน 1.0.2 อยู่บน GitHub ส่วนการเผยแพร่ใน Chrome Web Store ยังอยู่ระหว่างรอ

แนะนำ: GPU แยก NVIDIA RTX 30 ซีรีส์หรือใหม่กว่า พร้อม VRAM อย่างน้อย 8 GB และ RAM ระบบอย่างน้อย 8 GB

ติดตามข้อความ

ฟังในแบบของคุณ

ตั้งความเร็วได้ตั้งแต่ 0.5× ถึง 3× ข้ามโค้ด ปรับช่วงพัก และเลือกสีไฮไลต์

กลับมาอ่านต่อภายหลัง

อ่านต่อจากจุดที่หยุดไว้ ใช้ข้อความอ่านเพื่อค้นหาส่วนที่ต้องการ

ประมวลผลในอุปกรณ์เป็นค่าเริ่มต้น

เสียงในตัวทำงานบนอุปกรณ์ของคุณ

ไฟล์เสียงที่ขาดหายจะดาวน์โหลดจาก Hugging Face ไฟล์ในแคชใช้แบบออฟไลน์ได้กับเสียงและโหมดเดิม การล้างที่เก็บข้อมูลหรือเปลี่ยนโหมดอาจต้องดาวน์โหลดใหม่ PageNarrator ไม่ได้รับข้อความ PDF URL หรือประวัติการท่องเว็บของคุณเพื่อสร้างเสียงอ่าน
