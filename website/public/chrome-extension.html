Get PageNarrator

Recommended: a dedicated NVIDIA RTX 30 series GPU or newer, with 8 GB+ VRAM and 8 GB+ system RAM.

Read webpages, selected text, and PDFs aloud. Speech runs on your device. Free. No account or usage quota.

Install v1.0.1

Build the extension from the GitHub source. Previous release downloads are no longer available. The Chrome Web Store listing is not available yet.

  1. Follow the source build steps below to create the dist/ folder.
  2. Open chrome://extensions and enable Developer mode.
  3. Choose Load unpacked and select the dist/ folder.
  4. Open an article, click the PageNarrator toolbar icon, and choose Read page.
  5. Wait for the first voice download and setup to finish.

For local PDFs, enable Allow access to file URLs in the extension's details.

Get the source

Update an unpacked installation

Stop playback, update your local source copy, and run npm ci and npm run build. Keep the same dist/ folder path. Open chrome://extensions, click Reload on the existing entry, and refresh your reading tabs. Keeping the same extension identity preserves settings and saved positions. Removing the extension or clearing its storage deletes local reading data.

Voices and downloads

Kokoro has ten English voices. First setup downloads about 93 MB on CPU or 326 MB on GPU, including one voice. Another voice needs about 0.5 MB. It uses WebGPU when available, with a slower CPU / WebAssembly fallback. Experimental OmniVoice requires WebGPU with fp16 support and a separate download of about 1.35 GB.

Missing voice files download from Hugging Face. Cached files work offline for the same voice and processing mode. Changing either, clearing storage, or browser eviction may require another download.

Before you start

Use desktop Chromium 120 or newer. The hardware above is a recommendation, not a verified minimum. Performance depends on your device and document.

Follow highlights, use the transcript, resume saved positions, and set speed from 0.5× to 3×. Speech keeps running when you close the popup.

Setup help · Privacy

Build from source

Build the extension locally. Install Node.js 22.13+ (22.x) or 24+, then:

  1. Clone the repository and open a terminal in PageNarrator.
  2. Run npm ci.
  3. Run npm run build.
  4. Load dist/ through chrome://extensions.
