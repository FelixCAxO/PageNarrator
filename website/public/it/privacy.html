Informativa sulla privacy

Privacy

Ultimo aggiornamento: 26 ottobre 2026

Dati di lettura

PageNarrator elabora testo, PDF ed evidenziazioni nel browser. Le voci Kokoro integrate vengono eseguite localmente. Anche OmniVoice, sperimentale, viene eseguito sul tuo dispositivo. I file OCR in inglese sono inclusi nell’estensione. PageNarrator non riceve contenuti di lettura, URL o cronologia per la narrazione.

Download delle voci integrate

I file mancanti vengono scaricati da Hugging Face e dai suoi server di distribuzione. Questi ricevono il tuo indirizzo IP e i file richiesti. Hugging Face non riceve il testo da leggere. I file sono conservati nella cache del browser dell’estensione e funzionano offline con la stessa voce e modalità, anche dopo un riavvio. Cambiare voce o modalità, cancellare l’archiviazione o la rimozione automatica della cache da parte del browser può richiedere un nuovo download. Il codice eseguibile è incluso nell’estensione.

Documenti online

I PDF online vengono richiesti al server che li ospita. Il server riceve l’URL e le normali informazioni di connessione, e può ricevere le credenziali già presenti nel browser necessarie per aprire il documento. Questa operazione è distinta dalla generazione della voce.

Archiviazione dell’estensione

L’archiviazione locale dell’estensione contiene preferenze, voci scelte, diagnostica, URL e titoli di pagine e PDF, posizioni e un estratto di testo fino a 160 caratteri per posizione salvata. I modelli usano la cache del browser. Questi dati non vengono sincronizzati con i server di PageNarrator.

Uso limitato nel Chrome Web Store

Contenuti di lettura, URL, impostazioni, voci, diagnostica e posizioni vengono usati solo per lettura, evidenziazione e ripresa. PageNarrator non vende questi dati, non li usa per pubblicità o concessione di prestiti, non li trasferisce per scopi estranei e non permette alle persone di leggerli. PageNarrator rispetta le norme del Chrome Web Store sui dati degli utenti, inclusi i requisiti di uso limitato (Limited Use).

Sito web e assistenza

Il sito non contiene script pubblicitari o di tracciamento del comportamento. Cloudflare elabora i registri di hosting. I caratteri vengono forniti da questo sito senza richieste a Google Fonts. Le email di assistenza servono per rispondere e conservare la cronologia delle richieste.

Elimina i tuoi dati

Gli aggiornamenti rimuovono impostazioni dismesse per voci personalizzate, chiavi API e modelli importati. Le pulizie interrotte vengono ritentate automaticamente; i dati rimangono fino al completamento. Elimina dati locali e file vocali cancellando l’archiviazione dell’estensione o disinstallandola.

Per accesso, rettifica o cancellazione della corrispondenza con l’assistenza, o altre domande sulla privacy, scrivi a support@pagenarrator.com.
