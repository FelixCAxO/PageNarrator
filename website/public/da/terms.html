Brugsvilkår

Senest opdateret: 19. oktober 2026

1. Softwaren

PageNarrator er en gratis browserudvidelse, der læser websider, markeret tekst og PDF-filer op. Indbyggede stemmer kører lokalt.

2. Open source-licenser

PageNarrators oprindelige kode er licenseret under GNU General Public License, version 3 eller nyere (GPL-3.0-or-later). Tredjepartskomponenter beholder deres angivne licenser, herunder MIT License og Apache License 2.0. Disse vilkår begrænser ikke rettighederne efter disse licenser.

3. Tilladt brug

Du må ikke misbruge softwaren, forstyrre dens funktion, omgå browsersikkerhed, distribuere skadelig kode eller bruge den til at overtræde loven eller tredjepartsrettigheder.

4. Tredjepartstjenester

Softwaren bygger på browserudbydere, open source-komponenter, stemmemodeller, Hugging Face til download af indbyggede stemmer, Cloudflare-hosting og mailinfrastruktur. Deres egne vilkår kan gælde.

5. Opdateringer og tilgængelighed

PageNarrator kan udgive opdateringer, ændre funktioner eller indstille softwaren. Softwaren leveres efter tilgængelighed uden løfte om uafbrudt eller fejlfri drift.

6. Ansvar

I det omfang loven tillader det, er PageNarrator ikke ansvarlig for indirekte, tilfældige eller særlige skader, følgeskader eller erstatning med afskrækkende eller straffende formål. Vilkårene begrænser ikke rettigheder, der ikke lovligt kan begrænses.

7. Lovvalg og kontakt

Disse vilkår er underlagt svensk ret uden anvendelse af lovvalgsregler. Send spørgsmål til support@pagenarrator.com. Se også privatlivspolitikken.
