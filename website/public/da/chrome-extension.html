Hent PageNarrator

Anbefalet: en dedikeret NVIDIA-GPU i RTX 30-serien eller nyere, med mindst 8 GB VRAM og 8 GB system-RAM.

Lyt til websider, markeret tekst og PDF-filer. Talen dannes på din enhed. Gratis, uden konto eller forbrugskvote.

Installer v1.0.1

Byg udvidelsen fra kildekoden på GitHub. Tidligere versioner kan ikke længere downloades. Udvidelsen er endnu ikke tilgængelig i Chrome Web Store.

  1. Følg byggeanvisningerne til kildekoden nedenfor for at oprette mappen dist/.
  2. Åbn chrome://extensions, og aktivér Udviklertilstand.
  3. Vælg Indlæs udpakket, og vælg mappen dist/.
  4. Åbn en artikel, klik på PageNarrator-ikonet i værktøjslinjen, og vælg Læs siden op.
  5. Vent, indtil det første stemmedownload og klargøringen er færdige.

Aktivér Tillad adgang til filwebadresser i udvidelsens detaljer for lokale PDF-filer.

Hent kildekoden

Opdater en udpakket installation

Stop afspilningen, opdater din lokale kopi af kildekoden, og kør npm ci og npm run build. Behold samme sti til mappen dist/. Åbn chrome://extensions, klik på Genindlæs for den eksisterende udvidelse, og opdater dine læsefaner. Samme udvidelsesidentitet bevarer indstillinger og gemte positioner. Hvis du fjerner udvidelsen eller rydder dens lager, slettes lokale læsedata.

Stemmer og downloads

Kokoro har ti engelske stemmer. Første klargøring downloader cirka 93 MB til CPU eller 326 MB til GPU, inklusive én stemme. Hver ekstra stemme kræver cirka 0,5 MB. WebGPU bruges, når det er tilgængeligt; CPU / WebAssembly er det langsommere alternativ. Eksperimentelle OmniVoice kræver WebGPU med fp16-understøttelse og et separat download på cirka 1,35 GB.

Manglende stemmefiler downloades fra Hugging Face. Filer i cachen fungerer offline med samme stemme og behandlingstilstand. Skift af en af dem, ryddet lager eller browserens automatiske sletning af cachen kan kræve et nyt download.

Før du starter

Brug Chromium 120 eller nyere på en computer. Hardwaren ovenfor er en anbefaling, ikke et verificeret minimumskrav. Ydeevnen afhænger af din enhed og dit dokument.

Følg fremhævningerne, brug oplæsningsteksten, genoptag gemte positioner, og indstil hastigheden fra 0,5× til 3×. Oplæsningen fortsætter, når popupvinduet lukkes.

Hjælp til opsætning · Privatliv

Byg fra kildekoden

Byg udvidelsen lokalt. Installer Node.js 22.13+ (22.x) eller 24+, og gør derefter følgende:

  1. Klon kodelageret, og åbn en terminal i PageNarrator.
  2. Kør npm ci.
  3. Kør npm run build.
  4. Indlæs dist/ via chrome://extensions.
