Sådan virker det

Vælg teksten. Start oplæsningen.

PageNarrator udtrækker teksten og læser den op på din enhed.

1. Vælg, hvad du vil læse

Brug Læs siden op til at begynde ved det synlige afsnit eller en gemt position. Brug Læs markeringen op til markeret tekst. PageNarrator fjerner navigation og andre forstyrrende sideelementer, når det er muligt.

2. Klargør stemmen

De indbyggede Kokoro-stemmer kører på din enhed. Manglende filer downloades fra Hugging Face. WebGPU danner talen, når det er tilgængeligt; CPU / WebAssembly er det langsommere alternativ. Eksperimentelle OmniVoice kræver WebGPU med fp16-understøttelse og sit eget download.

Filer i cachen fungerer offline med samme stemme og tilstand. Hvis lageret ryddes, eller du skifter tilstand, kan et nyt download være nødvendigt.

3. Følg teksten

Fremhævninger følger talen. Brug oplæsningsteksten, sæt på pause, spring mellem afsnit, eller skift hastighed. Afspilningen fortsætter, når popupvinduet lukkes. Din læseposition gemmes lokalt.

4. Læs PDF-filer op

PDF-viseren holder dokumentet synligt, mens du lytter. Markér tekst, skift side, zoom, eller roter. Engelske scanninger bruger lokal tekstgenkendelse.
