PageNarrator 1.0.5

Escucha páginas web y PDF.

Extensión gratuita y de código abierto para Chrome y navegadores Chromium de escritorio.

Se recomienda una GPU dedicada para las voces multilingües y la clonación de voz.

Estas funciones requieren WebGPU con compatibilidad con fp16. Las GPU integradas compatibles podrían funcionar, pero su rendimiento no se ha verificado. La configuración sugerida con al menos 8 GB de VRAM y 8 GB de RAM del sistema es provisional, no un mínimo probado.

Kokoro solo con CPU: un procesador moderno de al menos 6 núcleos y al menos 8 GB de RAM del sistema. Cabe esperar un inicio más lento y posibles pausas entre segmentos de voz mientras se genera el audio.
