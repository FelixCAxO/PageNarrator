Документация

Слушайте документацию

Слушайте руководства, справочники API и инструкции, сохраняя страницу перед глазами.

Следите за текстом

Подсветка следует за речью. Используйте панель «Текст», чтобы найти раздел, изменить скорость или продолжить с места остановки.

Пропускайте код при необходимости

Включите Пропускать фрагменты кода на страницах с большим количеством кода. Паузы между разделами и цвета подсветки задаются в Дополнительных настройках.

Обрабатывайте внутреннюю документацию локально

Речь создаётся на вашем устройстве. PageNarrator не получает текст, URL или историю браузера для озвучивания.
