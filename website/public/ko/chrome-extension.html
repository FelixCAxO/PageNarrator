다운로드

PageNarrator 설치하기

권장: NVIDIA RTX 30 시리즈 이상의 외장 GPU, VRAM 8 GB 이상 및 시스템 RAM 8 GB 이상.

웹페이지, 선택한 텍스트 및 PDF를 소리 내어 읽습니다. 음성 합성은 기기에서 실행됩니다. 무료이며 계정이나 사용량 한도가 없습니다.

v1.0.2 설치

GitHub에서 v1.0.2을 다운로드하세요. 아직 Chrome 웹 스토어에 등록되어 있지 않습니다.

  1. ZIP 파일을 다운로드한 뒤 압축을 푸세요.
  2. chrome://extensions를 열고 개발자 모드를 켜세요.
  3. 압축해제된 확장 프로그램을 로드합니다를 선택하고 압축을 푼 폴더를 선택하세요.
  4. 기사를 열고 도구 모음의 PageNarrator 아이콘을 클릭한 다음 페이지 읽기를 선택하세요.
  5. 첫 음성 다운로드와 설정이 완료될 때까지 기다리세요.

로컬 PDF를 읽으려면 확장 프로그램의 세부정보에서 파일 URL에 대한 액세스 허용을 켜세요.

v1.0.2 다운로드소스 받기출시 안내

압축 해제하여 설치한 확장 프로그램 업데이트

재생을 멈추세요. 기존 확장 프로그램 폴더의 파일을 ZIP에서 압축을 푼 내용으로 교체하고 새로고침를 클릭한 뒤 읽기 탭을 새로고침하세요. 설정과 읽기 위치를 유지하려면 폴더 경로를 그대로 두세요.

음성과 다운로드

Kokoro에는 영어 음성 10개가 있습니다. 처음 설정할 때 음성 하나를 포함하여 CPU에서는 약 93 MB, GPU에서는 약 326 MB를 다운로드합니다. 음성을 하나 더 추가하면 약 0.5 MB가 필요합니다. 사용 가능하면 WebGPU를 사용하고, 그렇지 않으면 더 느린 CPU / WebAssembly 방식으로 실행됩니다. 실험적인 OmniVoice에는 fp16을 지원하는 WebGPU와 약 1.35 GB의 별도 다운로드가 필요합니다.

없는 음성 파일은 Hugging Face에서 다운로드합니다. 캐시한 파일은 같은 음성과 처리 모드에서 오프라인으로 사용할 수 있습니다. 음성이나 모드를 바꾸거나, 저장공간을 지우거나, 브라우저가 캐시를 삭제하면 다시 다운로드해야 할 수 있습니다.

시작하기 전에

데스크톱 Chromium 120 이상을 사용하세요. 위의 하드웨어 사양은 권장 사항이며 검증된 최소 사양은 아닙니다. 성능은 기기와 문서에 따라 다릅니다.

강조 표시와 텍스트 보기를 이용하고, 저장된 위치에서 이어 읽고, 속도를 0.5×~3×로 조절하세요. 팝업을 닫아도 읽기는 계속됩니다.

소스에서 빌드

기기에서 확장 프로그램을 빌드하세요. Node.js 22.13+ (22.x) 또는 24+를 설치한 다음 아래 단계를 따르세요.

  1. 저장소를 복제하고 PageNarrator 폴더에서 터미널을 여세요.
  2. npm ci를 실행하세요.
  3. npm run build를 실행하세요.
  4. chrome://extensions에서 dist/를 로드하세요.
