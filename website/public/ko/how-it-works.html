사용 방법

텍스트를 고르고 재생하세요.

PageNarrator가 텍스트를 추출하여 기기에서 소리 내어 읽습니다.

1. 읽을 내용 선택

현재 보이는 구간이나 저장된 위치에서 읽으려면 페이지 읽기를 사용하세요. 선택한 구절을 읽으려면 선택한 텍스트 읽기를 사용하세요. PageNarrator는 가능한 경우 탐색 메뉴와 불필요한 페이지 요소를 제외합니다.

2. 음성 준비

내장 Kokoro 음성은 기기에서 실행됩니다. 없는 파일은 Hugging Face에서 다운로드합니다. 사용 가능하면 WebGPU로 음성을 합성하며, CPU / WebAssembly는 더 느린 대체 방식입니다. 실험적인 OmniVoice에는 fp16을 지원하는 WebGPU와 별도의 다운로드가 필요합니다.

캐시한 파일은 같은 음성과 모드에서 오프라인으로 사용할 수 있습니다. 저장공간을 지우거나 모드를 바꾸면 다시 다운로드해야 할 수 있습니다.

3. 함께 따라 읽기

읽는 부분에 따라 강조 표시가 이동합니다. 텍스트를 확인하거나 일시 정지하고, 구간을 이동하거나 속도를 바꿀 수 있습니다. 팝업을 닫아도 재생은 계속됩니다. 읽던 위치는 기기에 저장됩니다.

4. PDF 읽기

PDF 뷰어에서는 들으면서 문서를 볼 수 있습니다. 텍스트 선택, 페이지 이동, 확대·축소 및 회전이 가능합니다. 영어로 된 스캔 문서는 로컬 OCR로 인식합니다.
