개인정보 보호

최종 업데이트: 2026년 10월 26일

읽기 데이터

PageNarrator는 브라우저에서 텍스트, PDF 및 강조 표시를 처리합니다. 내장 Kokoro 음성은 로컬에서 실행됩니다. 실험적인 OmniVoice도 기기에서 실행됩니다. 영어 OCR 파일은 확장 프로그램에 포함되어 있습니다. PageNarrator는 음성을 생성하기 위해 읽을 내용, URL 또는 방문 기록을 받지 않습니다.

내장 음성 다운로드

없는 파일은 Hugging Face와 해당 파일 배포 서버에서 다운로드합니다. 이 서버는 IP 주소와 요청한 파일 정보를 받습니다. Hugging Face는 읽을 텍스트를 받지 않습니다. 파일은 확장 프로그램의 브라우저 캐시에 저장되며, 재시작 후에도 같은 음성과 모드에서는 오프라인으로 사용할 수 있습니다. 음성이나 모드를 바꾸거나, 저장공간을 지우거나, 브라우저가 캐시를 삭제하면 다시 다운로드해야 할 수 있습니다. 실행 코드는 확장 프로그램에 포함되어 있습니다.

온라인 문서

온라인 PDF는 문서 호스트에 요청합니다. 호스트는 URL과 일반적인 연결 정보를 받으며, 문서를 여는 데 필요한 기존 브라우저 인증 정보를 받을 수도 있습니다. 이 과정은 음성 생성과 별개입니다.

확장 프로그램 저장공간

확장 프로그램의 로컬 저장공간에는 환경설정, 선택한 음성, 진단 정보, 페이지와 PDF의 URL 및 제목, 읽던 위치, 저장 위치마다 최대 160자의 텍스트 발췌가 저장됩니다. 모델 파일은 브라우저 캐시를 사용합니다. 이 데이터는 PageNarrator 서버에 동기화되지 않습니다.

Chrome 웹 스토어의 제한적 사용 정책

읽을 내용, URL, 설정, 음성, 진단 정보 및 위치는 음성 읽기, 강조 표시 및 이어 읽기에만 사용됩니다. PageNarrator는 이 데이터를 판매하거나 광고·대출에 이용하지 않으며, 관련 없는 목적으로 전송하거나 사람이 읽도록 허용하지 않습니다. PageNarrator는 제한적 사용 요건을 포함한 Chrome 웹 스토어 사용자 데이터 정책을 따릅니다.

웹사이트 및 지원

웹사이트에는 광고나 행동 추적 스크립트가 없습니다. Cloudflare는 호스팅 로그를 처리합니다. 글꼴은 이 웹사이트에서 제공하며 Google Fonts에 요청을 보내지 않습니다. 지원 이메일은 답변과 지원 기록 보관에 사용됩니다.

데이터 삭제

업그레이드 시 더 이상 사용하지 않는 사용자 지정 음성 설정, API 키 및 가져온 모델을 삭제합니다. 정리 작업이 중단되면 자동으로 다시 시도하며, 완료될 때까지 데이터가 남아 있습니다. 확장 프로그램의 저장공간을 지우거나 확장 프로그램을 삭제하면 로컬 데이터와 음성 파일을 제거할 수 있습니다.
