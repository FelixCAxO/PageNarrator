도움말

설정 및 도움말

권장: NVIDIA RTX 30 시리즈 이상의 외장 GPU, VRAM 8 GB 이상 및 시스템 RAM 8 GB 이상.

GitHub에서 v1.0.1을 다운로드하세요. 아직 Chrome 웹 스토어에 등록되어 있지 않습니다.

읽던 위치를 유지하며 업데이트

로컬 소스를 업데이트하고 npm ci와 npm run build를 실행하세요. dist/ 폴더 경로는 그대로 유지하세요. chrome://extensions에서 기존 항목의 새로고침을 클릭한 다음 읽고 있던 탭을 새로고침하세요. 업데이트 안내를 확인하세요. 확장 프로그램을 삭제하거나 저장공간을 지우면 저장된 읽기 데이터가 삭제됩니다.

설치

소스 설치 단계를 따르세요. 로컬 PDF에는 확장 프로그램 세부정보의 파일 URL에 대한 액세스 허용이 필요합니다.

음성 준비하기

인터넷에 연결하고 음성 준비 또는 페이지 읽기를 선택하세요. 음성 읽기가 시작되기 전에 없는 파일을 Hugging Face에서 다운로드합니다.

캐시한 음성과 처리 모드가 같으면 오프라인으로 사용할 수 있습니다. 다른 음성이나 모드를 사용하거나, 저장공간을 지우거나, 브라우저가 캐시를 삭제하면 다시 다운로드해야 할 수 있습니다. 설정에 실패하면 연결 상태를 확인한 후 다시 시도하세요.

처리 방식 선택

Kokoro는 WebGPU와 더 느린 CPU / WebAssembly 대체 방식을 지원합니다. 읽기를 시작하면 고급 설정에서 현재 처리 방식을 확인할 수 있습니다. 실험적인 OmniVoice에는 fp16을 지원하는 WebGPU와 약 1.35 GB의 다운로드가 필요합니다.

실제 하드웨어 등급별 성능은 검증되지 않았습니다. 성능은 기기와 문서에 따라 다릅니다.

문제 해결

선택한 텍스트 읽기를 사용하려면 먼저 구절을 선택하세요. 보호된 브라우저 페이지는 읽을 수 없습니다. 선택한 문서에 대해 웹사이트 접근 권한을 요청하면 허용하세요. 설정이나 읽기가 느리면 고급 설정에서 처리 방식을 확인하세요.

저장된 읽기 데이터와 음성 파일을 제거하려면 확장 프로그램의 저장공간을 지우거나 확장 프로그램을 삭제하세요.

문의

support@pagenarrator.com으로 이메일을 보내세요. 시도한 작업, 오류, Chrome 버전 및 현재 처리 방식을 알려 주세요. 비공개 텍스트와 문서 URL은 포함하지 마세요.
