PageNarrator 1.0.2

웹페이지와 PDF를 소리 내어 읽어줍니다.

Chrome 및 데스크톱 Chromium 브라우저용 무료 오픈 소스 확장 프로그램입니다.

확장 프로그램 받기사용 방법
  • 기기에서 실행되는 AI 음성
  • 음성 설정 후 오프라인 사용
  • 계정이나 사용량 제한 없음

긴 글을 위한 도구

읽기 도구

텍스트 따라가기

강조 표시, 텍스트 보기, 읽던 위치 저장 및 0.5×~3× 속도 조절을 지원합니다.

PDF를 열고 듣기

스캔한 PDF의 영어 텍스트를 기기에서 OCR로 인식합니다.

나에게 맞게 듣기

기기에서 실행되는 영어 음성 10개와 실험적인 다국어 OmniVoice를 제공합니다.

기본적으로 기기에서 처리

내장 음성은 기기에서 실행됩니다

누락된 음성 파일은 Hugging Face에서 다운로드됩니다. 캐시된 파일은 같은 음성과 모드에서 오프라인으로 사용할 수 있습니다. 저장 공간을 지우거나 모드를 바꾸면 다시 다운로드해야 할 수 있습니다. PageNarrator는 읽기용 텍스트, PDF, URL 또는 방문 기록을 음성 생성 목적으로 받지 않습니다.
