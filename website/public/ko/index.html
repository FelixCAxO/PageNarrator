PageNarrator 1.0.1

글을 듣고, 읽던 곳부터 이어가세요.

기기 내 음성으로 웹페이지와 PDF를 읽고 텍스트를 함께 강조 표시합니다. 무료이며 계정이나 사용량 제한이 없습니다. 버전 1.0.1 소스 코드는 GitHub에서 제공됩니다. Chrome Web Store 공개는 아직 대기 중입니다.

권장: NVIDIA RTX 30 시리즈 이상의 외장 GPU, VRAM 8 GB 이상 및 시스템 RAM 8 GB 이상.

확장 프로그램 받기사용 방법
  • 기기에서 음성 생성
  • 계정이나 사용량 제한 없음
  • 웹페이지, 선택한 텍스트 및 PDF

긴 글을 위한 도구

읽기 도구

필요한 부분만 읽기

기사와 가이드에서 본문을 추출하고, 가능한 경우 불필요한 페이지 요소를 제외합니다.

PDF를 열고 듣기

PDF를 보면서 들을 수 있습니다. 텍스트를 선택하고 페이지를 확대하거나 회전하세요.

텍스트 따라가기

페이지와 읽기 텍스트의 강조 표시가 음성을 따라갑니다.

나에게 맞게 듣기

속도를 0.5배부터 3배까지 설정하세요. 코드를 건너뛰고, 일시 정지 간격과 강조 색상을 조절할 수 있습니다.

나중에 이어 읽기

멈춘 위치부터 이어 읽으세요. 읽기 텍스트에서 원하는 구간을 찾을 수 있습니다.

기본적으로 기기에서 처리

내장 음성은 기기에서 실행됩니다

누락된 음성 파일은 Hugging Face에서 다운로드됩니다. 캐시된 파일은 같은 음성과 모드에서 오프라인으로 사용할 수 있습니다. 저장 공간을 지우거나 모드를 바꾸면 다시 다운로드해야 할 수 있습니다. PageNarrator는 읽기용 텍스트, PDF, URL 또는 방문 기록을 음성 생성 목적으로 받지 않습니다.
