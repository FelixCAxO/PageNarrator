Téléchargement

Télécharger PageNarrator

Recommandé : un GPU NVIDIA dédié de la série RTX 30 ou plus récent, avec au moins 8 GB de VRAM et 8 GB de RAM système.

Écoutez les pages web, le texte sélectionné et les PDF. La parole est générée sur votre appareil. Gratuit, sans compte ni quota d’utilisation.

Installer v1.0.1

Compilez l’extension à partir du code source sur GitHub. Les anciennes versions ne sont plus disponibles au téléchargement. La fiche du Chrome Web Store n’est pas encore disponible.

  1. Suivez les étapes de compilation ci-dessous pour créer le dossier dist/.
  2. Ouvrez chrome://extensions et activez le Mode développeur.
  3. Choisissez Charger l’extension non empaquetée, puis le dossier dist/.
  4. Ouvrez un article, cliquez sur l’icône PageNarrator dans la barre d’outils et choisissez Lire la page.
  5. Attendez la fin du premier téléchargement de voix et de sa préparation.

Pour les PDF locaux, activez Autoriser l’accès aux URL de fichier dans les détails de l’extension.

Mettre à jour une installation non empaquetée

Arrêtez la lecture, mettez à jour votre copie locale du code et exécutez npm ci et npm run build. Conservez le même chemin vers le dossier dist/. Ouvrez chrome://extensions, cliquez sur Recharger pour l’extension existante et actualisez vos onglets de lecture. Conserver l’identité de l’extension préserve les réglages et les positions enregistrées. Supprimer l’extension ou effacer son stockage supprime les données de lecture locales.

Voix et téléchargements

Kokoro propose dix voix en anglais. La première préparation télécharge environ 93 Mo pour le CPU ou 326 Mo pour le GPU, dont une voix. Chaque voix supplémentaire nécessite environ 0,5 Mo. WebGPU est utilisé lorsqu’il est disponible ; CPU / WebAssembly sert de solution de repli plus lente. OmniVoice, expérimental, nécessite WebGPU compatible avec fp16 et un téléchargement séparé d’environ 1,35 Go.

Les fichiers vocaux manquants sont téléchargés depuis Hugging Face. Les fichiers en cache fonctionnent hors ligne avec la même voix et le même mode de traitement. Changer l’un des deux, effacer le stockage ou la suppression automatique du cache par le navigateur peut nécessiter un nouveau téléchargement.

Avant de commencer

Utilisez Chromium 120 ou une version ultérieure sur ordinateur. Le matériel indiqué est une recommandation, pas un minimum vérifié. Les performances dépendent de votre appareil et de votre document.

Suivez le surlignage, utilisez la transcription, reprenez une position enregistrée et réglez la vitesse de 0,5× à 3×. La lecture continue lorsque vous fermez la fenêtre contextuelle.

Compiler à partir du code source

Compilez l’extension localement. Installez Node.js 22.13+ (22.x) ou 24+, puis :

  1. Clonez le dépôt et ouvrez un terminal dans PageNarrator.
  2. Exécutez npm ci.
  3. Exécutez npm run build.
  4. Chargez dist/ depuis chrome://extensions.
