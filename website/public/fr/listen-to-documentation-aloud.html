Documentation

Écoutez la documentation

Écoutez les guides, références d’API et manuels tout en gardant la page sous les yeux.

Suivez le texte

Le surlignage suit la lecture. Utilisez la transcription pour trouver une section, régler la vitesse ou reprendre où vous vous êtes arrêté.

Ignorez le code si nécessaire

Activez Ignorer les extraits de code sur les pages contenant beaucoup de code. Réglez les pauses entre sections et les couleurs de surlignage dans les réglages avancés.

Gardez la documentation interne en local

La parole est générée sur votre appareil. PageNarrator ne reçoit ni le texte, ni l’URL, ni l’historique de navigation pour la narration.
