PageNarrator 1.0.2

Écoutez le texte. Gardez le fil.

Écoutez des pages web et des PDF avec des voix locales et un surlignage synchronisé. Gratuit. Sans compte ni quota d’utilisation. Le code source de la version 1.0.2 est sur GitHub. La publication sur le Chrome Web Store est en attente.

Recommandé : un GPU NVIDIA dédié de la série RTX 30 ou plus récent, avec au moins 8 GB de VRAM et 8 GB de RAM système.

Pour les textes longs

Outils de lecture

Lisez l’essentiel

Extrayez le texte principal des articles et des guides, en écartant les éléments superflus lorsque c’est possible.

Ouvrez un PDF et écoutez

Gardez le PDF visible pendant l’écoute. Sélectionnez du texte, zoomez ou faites pivoter les pages.

Suivez le texte

Le surlignage suit la voix sur la page et dans le texte de lecture.

Écoutez à votre façon

Réglez la vitesse de 0,5× à 3×. Ignorez le code, ajustez les pauses et choisissez les couleurs de surlignage.

Revenez plus tard

Reprenez là où vous vous êtes arrêté. Retrouvez une section dans le texte de lecture.

Local par défaut

Les voix intégrées fonctionnent sur votre appareil

Les fichiers vocaux manquants sont téléchargés depuis Hugging Face. Les fichiers en cache fonctionnent hors ligne avec la même voix et le même mode. Effacer le stockage ou changer de mode peut nécessiter un nouveau téléchargement. PageNarrator ne reçoit pas vos textes, PDF, URL ni votre historique de navigation pour générer la voix.
