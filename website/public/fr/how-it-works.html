Comment ça marche

Choisissez le texte. Lancez la lecture.

PageNarrator extrait le texte et le lit à voix haute sur votre appareil.

1. Choisissez le texte à lire

Utilisez Lire la page pour commencer à la section visible ou à la position enregistrée. Utilisez Lire la sélection pour un passage sélectionné. PageNarrator retire la navigation et les éléments superflus de la page lorsque c’est possible.

2. Préparez la voix

Les voix Kokoro intégrées s’exécutent sur votre appareil. Les fichiers manquants sont téléchargés depuis Hugging Face. WebGPU génère la parole lorsqu’il est disponible ; CPU / WebAssembly est la solution de repli plus lente. OmniVoice, expérimental, nécessite WebGPU compatible avec fp16 et son propre téléchargement.

Les fichiers en cache fonctionnent hors ligne avec la même voix et le même mode. Effacer le stockage ou changer de mode peut nécessiter un nouveau téléchargement.

3. Suivez le texte

Le surlignage suit la lecture. Utilisez la transcription, faites une pause, passez d’une section à l’autre ou changez la vitesse. La lecture continue lorsque vous fermez la fenêtre contextuelle. Votre position est enregistrée localement.

4. Écoutez des PDF

Le lecteur PDF garde le document visible pendant l’écoute. Sélectionnez du texte, changez de page, zoomez ou faites pivoter le document. Les pages numérisées en anglais utilisent la reconnaissance de texte locale.
