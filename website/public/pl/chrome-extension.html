Pobieranie

Pobierz PageNarrator

Zalecane: dedykowany układ NVIDIA z serii RTX 30 lub nowszy, co najmniej 8 GB VRAM i 8 GB pamięci RAM.

Słuchaj stron internetowych, zaznaczonego tekstu i plików PDF. Mowa powstaje na Twoim urządzeniu. Bezpłatnie, bez konta i limitu użycia.

Zainstaluj v1.0.1

Zbuduj rozszerzenie z kodu źródłowego na GitHub. Poprzednie wydania nie są już dostępne do pobrania. Wpis w Chrome Web Store nie jest jeszcze dostępny.

  1. Wykonaj poniższe kroki budowania ze źródeł, aby utworzyć folder dist/.
  2. Otwórz chrome://extensions i włącz Tryb dewelopera.
  3. Wybierz Załaduj rozpakowane, a następnie folder dist/.
  4. Otwórz artykuł, kliknij ikonę PageNarrator na pasku narzędzi i wybierz Czytaj stronę.
  5. Poczekaj na zakończenie pierwszego pobierania głosu i przygotowania.

Dla lokalnych plików PDF włącz Zezwalaj na dostęp do adresów URL plików w szczegółach rozszerzenia.

Pobierz kod źródłowy

Aktualizacja rozpakowanej instalacji

Zatrzymaj odtwarzanie, zaktualizuj lokalną kopię kodu i uruchom npm ci oraz npm run build. Zachowaj tę samą ścieżkę folderu dist/. Otwórz chrome://extensions, kliknij Załaduj ponownie przy istniejącym wpisie i odśwież karty z czytanymi stronami. Zachowanie tożsamości rozszerzenia chroni ustawienia i zapisane pozycje. Usunięcie rozszerzenia lub wyczyszczenie jego pamięci usuwa lokalne dane czytania.

Głosy i pobieranie

Kokoro oferuje dziesięć głosów angielskich. Pierwsze przygotowanie pobiera około 93 MB dla CPU lub 326 MB dla GPU, w tym jeden głos. Każdy kolejny głos wymaga około 0,5 MB. W miarę dostępności używane jest WebGPU; CPU / WebAssembly stanowi wolniejszą alternatywę. Eksperymentalny OmniVoice wymaga WebGPU z obsługą fp16 i osobnego pobrania około 1,35 GB.

Brakujące pliki głosów są pobierane z Hugging Face. Pliki w pamięci podręcznej działają offline dla tego samego głosu i trybu przetwarzania. Zmiana jednego z nich, wyczyszczenie pamięci lub jej automatyczne usunięcie przez przeglądarkę może wymagać ponownego pobrania.

Zanim zaczniesz

Używaj Chromium 120 lub nowszego na komputerze. Wskazany sprzęt jest zaleceniem, a nie zweryfikowanym minimum. Wydajność zależy od urządzenia i dokumentu.

Śledź podświetlenia, korzystaj z transkrypcji, wracaj do zapisanych pozycji i ustawiaj szybkość od 0,5× do 3×. Czytanie trwa nadal po zamknięciu okna rozszerzenia.

Pomoc w konfiguracji · Prywatność

Budowanie z kodu źródłowego

Zbuduj rozszerzenie lokalnie. Zainstaluj Node.js 22.13+ (22.x) lub 24+, a następnie:

  1. Sklonuj repozytorium i otwórz terminal w PageNarrator.
  2. Uruchom npm ci.
  3. Uruchom npm run build.
  4. Załaduj dist/ przez chrome://extensions.
