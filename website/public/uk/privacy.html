Дані читання

PageNarrator обробляє текст, PDF і підсвічування у вашому браузері. Вбудовані голоси Kokoro працюють локально. Експериментальний OmniVoice також працює на вашому пристрої. Файли англійського OCR постачаються з розширенням. PageNarrator не отримує вміст для читання, URL-адреси чи історію перегляду для озвучення.

Завантаження вбудованих голосів

Відсутні файли завантажуються з Hugging Face та його серверів доставки. Вони отримують вашу IP-адресу й відомості про запитані файли. Hugging Face не отримує текст для озвучення. Файли зберігаються в кеші браузера для розширення й працюють офлайн для того самого голосу й режиму, зокрема після перезапуску. Зміна голосу чи режиму, очищення сховища або видалення кешу браузером може вимагати повторного завантаження. Виконуваний код постачається в розширенні.

Онлайн-документи

Онлайн-PDF запитуються із сервера, де розміщено документ. Цей сервер отримує URL-адресу та звичайні відомості про з'єднання, а також може отримувати наявні облікові дані браузера, потрібні для відкриття документа. Це окремий від генерації мовлення процес.

Сховище розширення

Локальне сховище розширення містить налаштування, вибір голосу, діагностичні дані, URL-адреси й заголовки сторінок і PDF, позиції та уривок тексту довжиною до 160 символів для кожної збереженої позиції. Файли моделей зберігаються в кеші браузера. Ці дані не синхронізуються із серверами PageNarrator.

Обмежене використання даних в Інтернет-магазині Chrome

Вміст для читання, URL-адреси, налаштування, голоси, діагностичні дані й позиції використовуються лише для озвучення, підсвічування та продовження читання. PageNarrator не продає ці дані, не використовує їх для реклами чи кредитування, не передає з іншою метою й не дозволяє людям читати їх. PageNarrator дотримується Політики щодо даних користувачів Інтернет-магазину Chrome, зокрема вимог щодо обмеженого використання.

Вебсайт і підтримка

На вебсайті немає рекламних скриптів або скриптів відстеження поведінки. Cloudflare обробляє журнали хостингу. Шрифти надаються з цього вебсайту без запитів до Google Fonts. Листи до служби підтримки використовуються для відповідей і збереження історії звернень.

Видалення даних

Оновлення видаляють застарілі налаштування власних голосів, ключі API та імпортовані моделі. Перерване очищення автоматично повторюється; дані залишаються до його завершення. Видаліть локальні дані й файли голосів, очистивши сховище розширення або видаливши розширення.

Щоб отримати доступ до листування зі службою підтримки, виправити чи видалити його або поставити інші запитання щодо приватності, напишіть на support@pagenarrator.com.
