Завантажити

Отримайте PageNarrator

Рекомендовано: дискретний GPU NVIDIA серії RTX 30 або новіший, щонайменше 8 GB відеопам’яті та 8 GB оперативної пам’яті.

Слухайте вебсторінки, виділений текст і PDF. Мовлення генерується на вашому пристрої. Безкоштовно. Без облікового запису й лімітів використання.

Встановлення v1.0.2

Завантажте v1.0.2 із GitHub. Сторінка в Інтернет-магазині Chrome ще не доступна.

  1. Завантажте ZIP-файл і розпакуйте його.
  2. Відкрийте chrome://extensions та ввімкніть Режим розробника.
  3. Виберіть Завантажити розпаковане розширення і вкажіть розпаковану папку.
  4. Відкрийте статтю, натисніть значок PageNarrator на панелі інструментів і виберіть Прочитати сторінку.
  5. Дочекайтеся завершення першого завантаження голосу та підготовки.

Для локальних PDF увімкніть Дозволити доступ до URL-адрес файлів у відомостях про розширення.

Оновлення розпакованого розширення

Зупиніть відтворення. Замініть файли в початковій папці розширення вмістом розпакованого ZIP-файлу, натисніть Перезавантажити та оновіть вкладки з текстом. Збережіть той самий шлях до папки, щоб не втратити налаштування й позиції читання.

Голоси та завантаження

Kokoro має десять англійських голосів. Під час першої підготовки завантажується приблизно 93 MB для CPU або 326 MB для GPU, включно з одним голосом. Кожен додатковий голос потребує приблизно 0,5 MB. За наявності використовується WebGPU, інакше — повільніший резервний варіант CPU / WebAssembly. Експериментальний OmniVoice потребує WebGPU з підтримкою fp16 та окремого завантаження обсягом приблизно 1,35 GB.

Відсутні файли голосів завантажуються з Hugging Face. Кешовані файли працюють офлайн для того самого голосу й режиму обробки. Зміна голосу чи режиму, очищення сховища або видалення кешу браузером може вимагати повторного завантаження.

Перед початком

Використовуйте настільний Chromium 120 або новіший. Зазначене вище обладнання є рекомендацією, а не перевіреним мінімумом. Швидкодія залежить від вашого пристрою та документа.

Стежте за підсвічуванням, користуйтеся текстом, продовжуйте зі збереженої позиції та встановлюйте швидкість від 0,5× до 3×. Читання триває після закриття спливного вікна.

Збирання з вихідного коду

Зберіть розширення локально. Встановіть Node.js 22.13+ (22.x) або 24+, а потім:

  1. Клонуйте репозиторій та відкрийте термінал у папці PageNarrator.
  2. Виконайте npm ci.
  3. Виконайте npm run build.
  4. Завантажте dist/ через chrome://extensions.
